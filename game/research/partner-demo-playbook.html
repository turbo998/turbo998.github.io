湾岸 Midnight → Scrap Swarm →

合作伙伴演示手册：3 分钟高管速览与 10 分钟技术深潜脚本

1. 演示目标与核心话术锚点

本手册供解决方案架构师（CSA/FDE）与技术合伙人在向游戏工作室、互动媒体客户或研发高管演示 HVE Agent 能力时使用。核心传达主线：

“如果说 HVE Harness 擅长制作一段令人惊艳的单次视觉动画，那么 HVE Agent 展示的是如何把这种视觉与动画表现力工程化为可交互、有剧情、零外部商业资产依赖、且经过 60Hz 确定性自动化验证的完整 3D/2D 游戏系统。”

2. 方案 A：3 分钟高管速览动线（Executive Pitch）

第 1 分钟：门户实时拆解舞台（无需跳转，一屏看懂三大引擎能力）

  • 打开 AI Gaming Lab 门户首页，指向中间的 Interactive Procedural Animation Benchmark Stage。
  • 在 Tab 1 (Wanan 3D Engine) 点击切换 RX-7 FD3S 与 Skyline GT-R BNR34，依次点亮：
  • 跳灯开合机构：展示参数化铰链旋转与车灯光锥；
  • 加减速俯仰与过弯侧倾：展示物理受力实时耦合车身姿态；
  • 换挡双出蓝紫回火与刹车盘灼热：展示瞬态粒子与热力发光；
  • 线框拓扑与轮拱开孔检视：证明每辆车均为真实开放轮拱几何而非贴图盒子。
  • 切到 Tab 2 (Scrap Swarm 2D Engine)，开启 番剧横向切入特写与黑白冲击帧，展示 R-17 爆铆枪后坐力抛壳、冲刺残影与赫克托破甲裂解。
  • 切到 Tab 3 (Echo & Comms)，点击 推进叙事状态机节点，展示零外部音频文件的 Web Audio 合成频谱与双转轮磁带机。

第 2 分钟：《湾岸 Midnight · 零点以东》实机体验

  • 点击 「在线畅玩 Wanan Midnight →」。
  • 点击 「开始故事」 进入上海篇第 1 章《末班灯》，向客户展示「回声车间」复古磁带机对话 UI 与车型选择台。
  • 发车进入卢浦大桥夜战，按住 W 加速、A/D 转向、S 重刹入弯，让客户观察车尾双出蓝紫回火、刹车盘灼热与上海外滩/卢浦大桥天际线。

第 3 分钟：《废土斗机祭 · Scrap Swarm》实机与设定集

  • 返回门户点击 「在线畅玩 Scrap Swarm →」。
  • 按 Space 展示 炉心冲刺残影，按 Q 触发 炉心觉醒番剧切入特写，展示多关节机甲的高速战斗手感与无线电剧情弹窗。
  • 点击 「角色与机体设定集 (Hangar) →」，在网页设定集中切换五台机甲的「巡航 / 攻击 / 觉醒 / 破甲」四态实时骨骼动画。

3. 方案 B：10 分钟架构师技术深潜脚本（Technical Deep Dive）

  • 0:00 – 2:30 | 参数化曲面建模 vs 传统静态资产管线
  • 结合 wanan-midnight-technical-assets.html，讲解如何用单个 TypeScript 目录（8 车系 44 代）驱动开放式轮拱、车顶拱冠与跳灯机构，把整包体积控制在 < 300 KB gzip。
  • 2:30 – 5:00 | 多关节状态机与番剧演出（Impact Frame）实现
  • 结合 scrap-swarm-technical-assets.html，拆解 R-17 的 6 层骨骼节点、抛物线弹壳物理、斜向速度线 Cut-in 与黑白冲击帧合成逻辑。
  • 5:00 – 7:30 | 零外部音频 Web Audio 合成与多幕叙事
  • 演示五类 JDM 引擎谐波合成器（转子、直六双涡轮、V6、水平对置、直四）+ 隧道双延迟混响，以及《零点以东》6 章与《废土斗机祭》3 幕反转叙事状态机。
  • 7:30 – 10:00 | 60Hz 确定性验证 Harness 与 CI 门禁
  • 打開浏览器控制台演示 window.__labStage.getState()，讲解固定步长物理（30/60/120Hz 一致性）、竞速期 0 动态建网守卫（modelsBuiltDuringRace === 0）与内建自动通关 Bot 如何在 GitHub Actions 中完成端到端回归。

Data flow / 门控分流与持续优化管线 (1–7) Data flow / Gated Routing & Optimization Pipeline (1–7)

  1. API 网关与内联安全检查：请求经 Foundry AI Gateway (APIM) 执行 TPM 配额、语义缓存与跨区容灾，并由 Guardrails 执行提示注入拦截与 PII 脱敏。 Gateway & Inline Safety Policy: Foundry AI Gateway (APIM) enforces TPM quotas, semantic cache & failover while Guardrails block prompt injection and redact PII.
  2. 校准概率判别评分：Microsoft-Decision-1.1 经 /v1/systemone 输出各候选动作的校准置信度分布（输出 Token $0 计费，延迟较生成式路由降低 >50%）。 Calibrated Probability Scoring: Microsoft-Decision-1.1 evaluates /v1/systemone calibrated action probabilities at $0 output token cost (>2× faster than generative routers).
  3. 高置信确定性执行（p ≥ τ_high）：落在高置信区间的标准化意图直接触发确定性工具调用，无需消耗高成本前沿推理模型配额。 Deterministic Fast Path (p ≥ τ_high): High-confidence standard intents execute deterministic APIs directly without invoking frontier reasoning models.
  4. 中等置信升级编排（τ_low ≤ p < τ_high）：多步骤复杂任务升级至 Foundry Agent Service 调度 MAI-Code-2 / GPT-6.2，并按隔离等级分发至对应计算沙箱。 Frontier Agent Escalation (τ_low ≤ p < τ_high): Multi-step tasks escalate to Foundry Agent Service (MAI-Code-2 / GPT-6.2) inside the appropriate isolated runtime.
  5. 低置信人工复核（p < τ_low）：低置信度或高风险写操作自动附带结构化上下文与候选建议转交人工审批队列。 Human-in-the-Loop Escalation (p < τ_low): Low-confidence or high-impact mutations route to human specialists with structured context and candidate evidence.
  6. OpenTelemetry 遥测评估与自动寻优：线上 OTel Trace 流入 Evaluate & Insights 识别失败簇，驱动 Agent Optimizer 离线寻优 Prompt 与 Tool Schema（未见测试集提升 +9.2 分）。 OTel Trace Evaluation & Auto-Optimization: Live OTel traces feed Evaluate & Insights failure clustering and Agent Optimizer prompt/schema search (+9.2 pts unseen lift).
  7. 轨迹蒸馏与回归灰度发布：通过 Managed / Programmed Training（SFT/RFT）将通过验证的高质量轨迹蒸馏至专用小模型，经离线评测门禁与人工审批后灰度上线。 Trace Distillation & Regression-Gated Rollout: Managed / Programmed Training (SFT/RFT) distills verified traces into compact models, promoted behind regression gates and human sign-off.

Design points / 架构师关键设计决策 Design points / Solution Architect Decisions

  • 前置校准概率分类器控制推理成本与延迟：以 Decision-1.1 三阈值门控替代全量前沿模型意图分类，路由层开销降低 85% 以上且中位时延控制在 ~240 ms。 Front-load calibrated probability triage: Replaces 100% frontier LLM classification with Decision-1.1 3-band thresholds, cutting routing spend by 85%+ at ~240 ms P50 latency.
  • 按安全隔离等级与负载形态选择运行时：托管 PaaS 承载常规编排、Foundry on AKS 满足私有 VNet/GPU 合规驻留、ACA 承载事件驱动缩零任务、AKS Agent Sandbox 提供 Kata 微虚机内核隔离。 Match runtime to isolation boundary & load profile: Managed PaaS for standard orchestration, Foundry on AKS for private VNet GPUs, ACA for scale-to-zero bursts, and AKS Agent Sandbox for Kata microVM isolation.
  • 基于 OpenTelemetry 解耦评估管线与开发框架：支持 LangGraph、Semantic Kernel 或自研框架通过标准 OTel Span 无侵入接入评测与 Agent Optimizer（评分人机一致率 65% → 81%）。 Decouple evaluation from SDK choice via OpenTelemetry: Ingests standard OTel spans from LangGraph, Semantic Kernel, or custom code into Agent Optimizer (65% → 81% SME rubric alignment).
  • 外部写操作强制幂等设计与预算熔断：所有业务系统变更接口须校验幂等键，结合输入/工具/输出四节点策略检查与 Fleet & Cost Controls 配额上限防止异常循环消耗。 Enforce idempotent mutations & budget circuit breakers: Requires idempotency keys on external writes, 4-stage guardrail checks, and Fleet & Cost Controls caps against runaway loops.

Why Microsoft · 运行时与工程平台优势 Why Microsoft · Runtime & Engineering Platform Advantages

  • 公有云托管与私有 AKS 保持同一套 SDK 契约：应用代码无需重写即可在全托管 Foundry 服务与客户自持 Foundry on AKS 专属集群之间迁移。 Unified API contract across Managed PaaS and private AKS: Workloads move between turnkey Foundry PaaS and customer-managed Foundry on AKS VNet GPU clusters without code rewrites.
  • 路由、专项与旗舰三级模型成本梯度：Decision-1.1（$0 输出）+ MAI-Code-2（~40% 成本实现近前沿编码）+ GPT-6.2 Sol（12h Prompt Cache）组合优化单任务 TCO。 Three-tier first-party model cost hierarchy: Combines Decision-1.1 ($0 output), MAI-Code-2 (~40% cost near-frontier coding), and GPT-6.2 Sol (12h cache TTL) to optimize per-task TCO.
  • 内核级微虚机隔离与亚秒级内存状态恢复：AKS Agent Sandbox 集成 Kata microVM、Pod Snapshot 与 Cobalt 200 Arm64 算力，兼顾不可信代码安全隔离与有状态会话冷启动速度。 Kernel microVM isolation with sub-second snapshot restore: AKS Agent Sandbox pairs Kata microVMs, Pod Snapshot, and Cobalt 200 Arm64 nodes for secure stateful code & UI agents.
  • 评估、寻优与强化蒸馏同平台闭环：统一集成 11,000+ 模型目录、AI Gateway（GA）、OTel 评测与 SFT/RFT 训练管线，降低多工具链集成运维成本。 Integrated Evaluate → Optimize → Distill lifecycle: Unifies 11,000+ models, AI Gateway (GA), OTel trajectory evals, and SFT/RFT distillation in a single control plane.

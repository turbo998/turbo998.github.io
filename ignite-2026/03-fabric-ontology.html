Design points / 架构师关键设计决策 Design points / Solution Architect Decisions

  • 以零拷贝联邦替代跨云全量 ETL 同步：源端数据保留在既有 AWS S3、Databricks 与 Salesforce 存储中，消除重复存储开销与 T+1 批处理延迟。 In-place federation over cross-cloud ETL: Keeps source data inside existing S3, Databricks & Salesforce stores, eliminating duplicate storage costs and T+1 batch latency.
  • 以受控语义本体替代直接表级 Text-to-SQL：阻断大模型对数百张复杂 ERP 物理表自行拼装 JOIN 的错误风险，强制收敛至经审计的实体路径与 DAX 度量。 Governed Ontology over raw-table Text-to-SQL: Prevents LLMs from improvising error-prone SQL joins across hundreds of ERP tables by enforcing audited entity paths and DAX measures.
  • 以 HorizonDB 衔接分析洞察与在线事务：通过 Serverless PostgreSQL 跨湖仓查询卸载与 Reverse ETL，在不拆分 OLTP/OLAP 链路的前提下支撑运营应用状态持久化。 Bridge OLAP insights and OLTP state via HorizonDB: Pairs Serverless PostgreSQL DW-offloaded joins with Reverse ETL and Rayfin to persist operational state cleanly.
  • 安全策略下沉至存储与语义层：无论上层接入第一方还是第三方模型客户端，统一在 OneLake 与 Ontology 层实施 Entra OBO 身份透传与 RLS/CLS 过滤。 Enforce security at the storage and semantic layer: Applies Entra OBO identity propagation and OneLake RLS/CLS uniformly across both first-party and third-party model clients.

  • 内生应用与智能体数据库运维：Rayfin & Fabric Apps（GA，预览期已诞生 100,000+ 应用）与 Copilot Managed Runtime + Fabric（GA）自带认证、后端与 OneLake 治理；配合 Reverse ETL、Database Hub（GA）及 SQL/PG Database Agents（Preview）。 Governed App Backend & DB Agents: Rayfin & Fabric Apps (GA, 100,000+ apps built since preview) and Copilot Managed Runtime + Fabric (GA) wire auth, DBs, and APIs under OneLake Governance Hub, paired with Reverse ETL, Database Hub (GA), and SQL/PG Database Agents (Preview).

1. Quick Start / 如何启动演示 (2 Ways)

Option A: 1-Click Local Server (Recommended for Full 3D WebGL)

Because browsers restrict file:// CORS requests for 3D .glb models, NASA MOLA .bin elevation files, and ES modules, launch the included zero-dependency local server:

  • Windows: Double-click start-demo-windows.bat
  • macOS / Linux: Run sh start-demo-mac-linux.sh or node server.mjs
  • Python Fallback: Run python -m http.server 8788

Then open http://127.0.0.1:8788/ in Chrome or Edge.

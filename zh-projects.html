03ENGINEERING CASE STUDIES & FLAGSHIP BUILDS

精选工程：从十万沙箱底座、可复现评测到行业生产智能体

Azure AI Agent Infra — AKSClaw (Kata) × E2B 十万并发微虚拟机沙箱底座

Kata Cloud Hypervisor · E2B Firecracker · Standard_D96as_v7

针对大规模 Coding Agent、Computer-Use Agent 与不可信代码执行场景，设计四层（Build · Run · Ground · Govern）参考架构与六级运行时光谱。构建离线确定性 H5 仿真工作台、容量计算器与 41 套生产级 Bicep/K8s/SEV-SNP/Zero-Trust/FinOps 蓝图，量化验证单节点 512 沙箱高密混部与跨区域双活容灾。

成果：在 Standard_D96as_v7 上实现 108ms Base / 132ms Code-Interpreter 内存快照恢复、220 节点承载 100,000 并发沙箱、3.67s 跨区域热备故障切换（在线仿真 · 7-Card 报告）。

7-Card 4:5 可复现模型评测引擎与三方 Agent Harness 盲测竞技场

benchmark-harness-engineering · SKY-001 · Pelican Arena

构建端到端模型与智能体评测框架 benchmark-harness-engineering，强制执行零虚构坐标、密封 JSON 数据驱动与选项翻转鲁棒性检验。落地《SKY-001 19 模型编码智能体基准》《Decision-1 路由模型 6-Way 帕累托对比》及《FAF v2.0.1 vs AGENT-FORGE v0.3.0 vs HVE-Core v3.3.101 三方盲测竞技场》。

成果：确立 7-Card 4:5 标准化评测交付物，揭示小参数微调路由模型在翻转扰动下高达 82pt 的置信度塌缩，并量化验证三方 Harness 工程规范得分（90.5 vs 91.8 vs 93.4）。

医药企业 AI 套件 — 多智能体 + 私有化大模型

Multi-Agent · 知识图谱 · vLLM on AKS

一家头部医药企业需要在稽查就绪、医学写作与生物统计场景部署 AI——严格的 GxP、数据主权与全程审计要求排除了 SaaS 大模型。设计多智能体内核（数据摄入 → 向量化 → 主题聚类 → 风险打分 → 跨流程知识图谱 → 答复起草），配置严格引用护栏；构建角色驱动的模拟稽查引擎；在 Azure 中国上架构私有化蒸馏大模型（vLLM on AKS、Entra ID SSO、全程审计日志）。

成果：稽查就绪准备从数周压缩到数天；结构化“逐条法规检查”看板取代数千页人工审阅；成为医药垂直行业的伙伴主导参考架构。

企业知识与线索发现智能体

Azure AI Foundry · 多模态 RAG · Browser-use

售后与售前团队被淹没在跨产品手册（文本 + 表格 + 图纸）的人工查询与网络线索调研中。构建生产级智能体：多模态 RAG 管线实现高精度表格与图形抽取；线索发现智能体结合 Grounding-with-Bing-Search + Browser-use；“知识库优先 + Web 兜底”模式带反馈闭环自我纠错。

成果：以 $20K ACR 赢单、交付周期 3 周；线索调研从数天压缩到数分钟；锁定二期微信集成与 Power Platform 增购。

Copilot Studio 上的 No-Code 多智能体 — RFQ 审批与全球客服

Copilot Studio + Azure OpenAI

在 no-code 平台上交付快速见效的 Agentic AI：为工业客户设计文档合规检查与审批路由的多智能体流程（含 human-in-the-loop 检查点）；为头部中国汽车 OEM 构建 24×7 多语言海外客服智能体，业务负责人可自行迭代。

成果：审批周期从数天到数小时；OEM 客服实现 100% 接待率、亚秒级响应、成本降低 75%、人工工作量减少 60%、线索量提升 300%。

GitHub Copilot 工程化工作坊 — 大中华区企业赋能

GHCP + MCP + Azure DevOps

8 小时、9 模块实操项目，端到端展示生产级 Copilot：ASP→AKS 容器化、FinOps 自动化、高级提示与上下文绑定、User-Story → Task 拆解、MCP-Server 集成、AI 辅助测试生成，以及 Azure DevOps 上的 Copilot CI/CD。

成果：大中华区 10+ 场、1,000+ 参会者、撬动 500+ Copilot 席位——把采用从“IDE 试用”变为可复制的团队级工程实践。

AI 文档助手 — 医药企业（2025 AWS 中国峰会主题演讲）

多模态 LLM · 评测 · 提示工程

提升 CSR（临床研究报告）纠错验证效率：定义项目成功标准、设计 LLM 评测与提示工程方案，推动“最后三公里”工程——多模态数据预处理与召回/精确率调优。

成果：为药物研究部门每年优化 180 人天；90% 召回率、61.5% 精确率；作为参考案例在 2025 AWS 中国峰会主题演讲发布。

云安全加固 — 跨国零售企业

SIEM · Splunk on AWS · 等保 2.0

为满足等保 2.0 构建云上 SIEM：高可用 Splunk 架构与容量规划优化、多种数据采集方式，以及 Ansible / Python / IaC 构建的 30+ 自动化运维模块。

成果：大中华区云上最大 Splunk 集群——ARR $10M、支撑 1,000+ 应用、每日 3 TB 日志摄入、100 并发查询；引入 MSSP 持续运营模式。

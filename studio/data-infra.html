PRE-INTEGRATED ENTERPRISE DEMO TOPOLOGY · SANITIZED PUBLIC ARCHITECTURE

Why Solution Architects use the Diamond Environment for Customer PoCs

Traditional PoCs stall on cross-service authentication, empty synthetic tables, and disconnected BI slides. The Diamond pattern unifies Entra ID OBO identity, M365 Teams collaboration, Microsoft Fabric (OneLake, Eventhouse KQL, Fabric IQ), and Azure Databricks (Unity Catalog, AI/BI Genie, Lakebase) over real-scale industry datasets.

SA WORKLOAD SELECTION MATRIX · FABRIC VS DATABRICKS VS BETTER TOGETHER

When to choose Microsoft Fabric, Azure Databricks, or Zero-Copy Coexistence

Architecture Dimension Microsoft Fabric Native (TCL Demo) Azure Databricks Native Fabric × Databricks Better Together (Zava Demo)
Core PositioningEnd-to-end SaaS data, real-time analytics, business ontology & M365 BI platformCode-first Spark/Photon lakehouse, complex ETL, ML/AI engineering & Unity CatalogDatabricks transforms & governs Bronze/Silver/Gold; Fabric serves 0-DBU Direct Lake BI & Teams actions
Storage & FormatOneLake open Delta Parquet + Zero-Copy Shortcuts across ADLS / S3 / GCSADLS Gen2 open Delta Lake + Liquid Clustering + Predictive OptimizationSingle Delta Parquet copy on Azure; Mirrored Azure Databricks Catalog eliminates scheduled copy pipelines
Semantic & AI LayerFabric IQ Ontology + Data Agent + Operations Agent + Copilot in Power BIUnity Catalog Metric Views + AI/BI Genie conversational SQL + Mosaic AI AgentsGenie empowers data/ops analysts on Gold tables while Fabric IQ & Copilot Studio drive M365 workflows
Real-Time & Operational StateReal-Time Intelligence (Eventstreams + Eventhouse KQL + Activator alerts)Structured Streaming + Delta Live Tables (DLT) + Serverless Lakebase (Postgres)Eventhouse handles sub-second IoT/logistics telemetry; Lakebase/Pipelines persist approved dispatch orders
BI & Executive ConsumptionNative Power BI Direct Lake over OneLake (sub-second, zero import refresh)AI/BI Dashboards + Serverless SQL Warehouse (billed per DBU query workload)Direct Lake reads mirrored Gold tables directly from OneLake with 0 SQL Warehouse DBU cost
Commercial & FinOps ModelUnified Capacity Units (F-SKU pool shared across Data Factory, KQL, Spark & BI)Workload-isolated DBU + Azure VM/Serverless compute with granular cluster policiesRight-size Databricks DBU strictly for heavy ETL/ML while pooling org-wide BI on existing Fabric/P-SKU

技术维度 底层通信原语与频次 改善的核心指标 架构师设计红线与最佳适用模型
TP (张量并行) 每层 2 × AllReduce (70B 每词 160 次同步) 同时降低 TTFT 与 TPOT，分摊单卡权重显存 ⛔ 严禁跨机！必须锁死在单机 NVLink (TP≤8) 或 NVL72 超节点内；Dense 70B 选 TP=4
PP (流水线并行) 仅跨节点边界 1 × P2P Send/Recv 以极低跨网带宽将超大稠密模型切分到多机 Dense 405B 跨双机 8x H100 (80GB) 首选 机内 TP=8 × 跨机 PP=2
Attention DP (数据并行) Attention 层 0 通信 (独立副本处理不同请求) 线性扩展集群 QPS/TPS，消除 MLA/GQA KV 跨卡复制 DeepSeek 671B MLA 必开 --enable-dp-attention，使可用 KV 容量翻 8~16 倍
Expert EP (专家并行) 每层 2 × All-to-All (Dispatch + Combine) 将 256 个稀疏路由专家均摊至多卡，保持单次仅激活 37B MoE 大集群标配 DeepEP (IBGDA) + 双微批重叠 + EPLB 冗余专家
MTP / EAGLE-3 投机解码 单步验证 3~4 个候选词 (零额外跨机原语) 中低并发 (B≤48) 下将 TPOT 压降 1.9x–2.5x 设置 B > 64 自动关断阈值，避免高并发算力饱和期验证开销反噬
Block-FP8 + Prefix Cache 通信字节数减半 + 跳过已缓存前缀计算 TTFT 降 3.5x–6x、TPOT 降 1.9x、并发翻倍 Hopper/Blackwell 生产标配；前端网关必须配 KV-Aware 前缀哈希粘性路由

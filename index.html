    PILLAR 04 · SYSTEM ONE ROUTING & DECISION MODELS (`turbo998/benchmark-harness-engineering`)

    Agent 架构的「System One 快思考层」：0–1 Token 前向评分、置信度门控与成本暴降 94%

    用 2B 专用决策模型或 Microsoft-Decision-1 承担高频意图分流、升级判定与工具预检，消除通用 LLM 自回归解码延迟与高昂账单。

    ⚡ Strands Decider 2B (`strands-decider-2B-qwen3.5-v1-2610`)

    • 零输出 Token 机制：服务端将 JSON 渲染为 <state> + <question> + <options> + <answer> 纯文本，模型在 <answer> 处单次前向传播匹配各选项末尾 token 隐状态并经 softmax 输出概率。
    • 单次调用三连判 (~170 ms)：同时输出 intent (choice: billing_dispute 93.9% → Auto)、escalate (noul: Yes 94.7% → Auto)、urgency (score: 1.71/3 置信度 0.377 → 拦截转人工)。
    • 7 场景 12 决策实测：11/12 方向正确；唯一参数幻觉失误仅 53% 置信度，被 <0.9 门控稳稳拦在 Confirm 分档。
    • 逆序零翻转 & 批处理加速：6/6 选项顺序反转首选答案 100% 不变；共享 <state> 前缀合并 10 题耗时从 710ms 降至 365ms (0.51x)。

    📈 Microsoft-Decision-1 四引擎 480 次路由评测

    • 准确率与成本双向碾压通用 LLM：在 40 个中英双语请求 × 3 轮（每引擎 120 次决策）中，Microsoft-Decision-1 取得 113/120 (94.2%) 匹配率，高于 gpt-4.1-mini 的 108/120 (90.0%)。
    • 百万次成本仅 $8.6（降低 94%）：Decision-1 每次仅输出 1 token（平均输入 205），百万次决策仅需 $8.6，而 gpt-4.1-mini（输出 35 tokens）高达 $141.8。
    • P50 延迟缩短 62%：East US 2 跨洋调用 P50 仅 541 ms（vs LLM 1430 ms）；TypeSafe Jev 达 98.3% / 350 ms / $21.7。
    • 0.60 置信度门控定律：Decision-1 的 7 次错误概率均 ≤ 0.56，108/113 正确项 > 0.60；同时也证明 4-bit 量化模型（OpenJev 失误在 0.70–0.72）必须重新校准阈值。

    ARCHITECTURAL SYNERGY · HOW THE 4 PILLARS FIT TOGETHER

    四大技术栈如何组装成下一代企业级 Agent 与互动娱乐产品？

    以「智能座舱 / 游戏实时交互 NPC / 跨国品牌全渠道客服」为例的端到端协同流水线：

    Step 1 · 声学感知层 (Voice)

    < 200ms 实时接入与抗噪

    • WebRTC Opus 弱网抗损 + 远场波束成形 + Semantic VAD。
    • turnEpoch 状态机在用户插话 165ms 内清空旧下行缓冲。
    • 实时输出流式转写与声学情绪特征。

    Step 2 · 毫秒门控层 (Decision)

    ~170ms System One 路由

    • Strands Decider 2B 或 Microsoft-Decision-1 单次前向传播并行判定：意图分类、安全风险、是否需要高阶推理。
    • ≥0.90 直接走快路径；低置信度或写操作进入 Confirm / Human 审批态。

    Step 3 · 视觉/空间表现层 (Anim & Game)

    60fps 零资产包负担渲染

    • Blender 4.5 MCP 离线烘焙高精度 GLB/法线贴图 + 浏览器参数曲面/多关节骨骼实时驱动。
    • Web Audio 合成引擎谐波或空间混响，实现音画与物理姿态毫秒级同步。

    Step 4 · 契约与评测层 (Harness)

    100% 确定性安全与回归

    • Zod 严格工具 Schema + pending_approval 不可变版本锁 + K05 物理安全硬熔断。
    • 60Hz 帧步进 Harness + 90 项语音探针 + 7-Card 基准报告封存验收。
    核心竞争壁垒：前端极致体验（620ms 语音 + 60fps 3D/2D 渲染） × 后端金融级确定性治理（0 越权、94% 路由降本） Slide 7 / 8

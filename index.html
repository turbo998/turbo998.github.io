03Project Highlights

Selected engagements, PoC → production

Pharma Enterprise AI Suite — Multi-Agent + Private LLM

Multi-Agent · Knowledge Graph · vLLM on AKS

A top pharma enterprise needed AI for inspection readiness, medical writing and bio-stats under strict GxP, data-sovereignty and audit-trail requirements that ruled out SaaS LLMs. Designed the multi-agent core (ingestion → embedding → topic clustering → risk scoring → cross-process knowledge graph → response drafting) with strict citation guardrails, a persona-driven mock-inspection engine, and a private-hosted distilled LLM on Azure China (vLLM on AKS, Entra ID SSO, full audit logging).

Result: inspection-readiness preparation collapsed from weeks to days; a structured "case-by-case regulation checks" dashboard replaced thousands of pages of manual review; now the partner-led reference architecture for the pharma vertical.

Enterprise Knowledge & Lead-Discovery Agent

Azure AI Foundry · Multi-Modal RAG · Browser-use

After-sales and pre-sales teams were buried in manual lookups across manuals (text + tables + drawings) and manual web lead-research. Built a production agent combining multi-modal RAG with high-precision table & figure extraction, a lead-discovery agent using Grounding-with-Bing-Search + Browser-use, and a "knowledge-base first + web fallback" pattern with feedback-loop self-correction.

Result: won at $20K ACR with a 3-week lead time; lead research compressed from days to minutes; Phase-2 WeChat integration and Power Platform upsell secured.

No-Code Multi-Agent on Copilot Studio — RFQ Approval & Global Customer Service

Copilot Studio + Azure OpenAI

Delivered fast-time-to-value agentic AI on a no-code surface: a multi-agent flow for document compliance checking and approval routing with human-in-the-loop checkpoints for an industrial customer, and a 24×7 multi-language overseas customer-service agent for a leading Chinese auto OEM that LoB owners iterate on themselves.

Result: approval cycles from days to hours; OEM service hit 100% reception, sub-second response, 75% cost reduction, 60% less manual workload, and 300% lead-volume uplift.

GitHub Copilot Engineering Workshop — GCR Enterprise Enablement

GHCP + MCP + Azure DevOps

An 8-hour, 9-module hands-on program showing production-grade Copilot end-to-end: ASP→AKS containerization, FinOps automation, advanced prompting & context binding, User-Story → Task decomposition, MCP-Server integration, AI-assisted test generation, and Copilot-driven CI/CD on Azure DevOps.

Result: 10+ workshops across GCR, 1,000+ attendees, 500+ Copilot seats unlocked — adoption moved from "IDE trial" to repeatable team-level engineering practice.

AI Documentation Assistant — Pharma (AWS China Summit 2025 Keynote)

Multimodal LLM · Evaluation · Prompt Engineering

Improved CSR (Clinical Study Report) correction-validation for a pharma customer: defined success criteria, designed LLM evaluation and prompt engineering, and drove "Last 3 Miles" engineering including multimodal data pre-processing and recall/precision tuning.

Result: 180 man-days/year saved for drug research; 90% recall and 61.5% precision; published as a keynote reference at AWS China Summit 2025.

Cloud Security Reinforcement — MNC Retail

SIEM · Splunk on AWS · MLPS 2.0

Built a cloud SIEM for MLPS 2.0 compliance: high-availability Splunk architecture with optimized capacity planning, multiple data-collection methods, and 30+ automation modules in Ansible / Python / IaC.

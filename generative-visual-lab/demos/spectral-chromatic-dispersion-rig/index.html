为什么许多后处理色差（Chromatic Aberration）教程写的“把红、绿、蓝三个通道分别按不同径向缩放采 3 次（`3-Tap RGB Split`：`R = tex(x − 6px).r`，`G = tex(x).g`，`B = tex(x + 6px).b`）”，一旦拉大镜头边缘的色散跨度（如 `Δr = 12.0 px`），画面边缘原本宽度为 `w = 1.5 px` 的精细金属高光、星点或字幕边缘不会变成柔和真实的光学彩虹色散，反而会直接裂开成**三个完全断开的孤立纯红、纯绿、纯蓝重影（3D-Glasses RGB Ghosting）**？因为真实镜头玻璃根据柯西色散定律把 `400 ~ 700 nm` 的连续可见光谱平滑铺开在了整段 `12.0 px` 上，而朴素 3 抽头分离只采了红、绿、蓝三个离散点！在红光（`−6 px`）与绿光（`0 px`）中间的第 4、5、6 站（`x = −4, −3, −2 px` 橙黄光谱带）以及绿光与蓝光中间的第 10、11、12 站（`x = +2, +3, +4 px` 青色光谱带）共 `6/17` 个站点上，3 抽头采样完全落空，输出 `0.0000` 死黑断层；而在 3 个重影中心又冲高至 `0.3333`（`2.67×` 尖峰失真，污染 `15/17` 站）！采用 Playdead《INSIDE》与 Unreal Engine 5 所用的**连续光谱查找表积分（Continuous Spectral-LUT Dispersion）**，沿色散向量连续积分并由光谱权重归一化，可在 `x ∈ [−4, +4] px` 全程塑造恒定 `L_disp = w / Δr = 0.1250` 的丝滑无缝彩虹平台（`0` 死黑断层、`0` 三重鬼影）！An original 17-station 3D spectrograph bench compares continuous spectral-LUT chromatic dispersion against naive 3-tap RGB channel split ghosting.

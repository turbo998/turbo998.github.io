为什么在屏幕空间反射（Screen-Space Reflections, SSR）和屏幕空间全局光照（SSGI）中，如果你把一条从近处地面起点（`z₀ = 2.0 m`）射向远处墙面终点（`z₁ = 34.0 m`）的三维反射射线投影到二维屏幕像素坐标 `u ∈ [0, 1]` 上，然后直接在屏幕空间对线性深度做均匀插值 `z_naive(u) = (1 − u)·z₀ + u·z₁`，这条本该笔直的反射光线会在三维空间里向场景深处**剧烈弯曲成一条抛物/双曲弧线（Hyperbolic Ray Bowing）**，一头撞进原本根本没挡路的 `z = 8.0 m` 中景立柱背后？因为在透视投影（`x_screen ∝ X / Z`）下，屏幕像素坐标 `u` 与三维深度 `z` 之间是分式线性（齐次射影）关系，**只有倒数深度 `q(u) = 1 / z(u)` 才与屏幕像素步长 `u` 严格成线性关系**！在屏幕中点（第 8 站 `u = 0.50`）处，真实三维直线的深度仅仅只有 `z_true(0.50) = 2×34 / (17 + 1) = 3.7778 m`（轻松从 `8.0 m` 立柱前方穿过）；而朴素屏幕空间线性 Z 插值算出的却是算术平均 `0.5×(2 + 34) = 18.0000 m`——**将射线深度凭空往深处掰弯了 `+14.2222 m`（深了 `4.76×`，在第 11 站峰值误差达 `+18.3333 m`），导致全段 `15/17` 个内部屏幕步进点发生严重轨迹弯曲与假自交**！采用 Morgan McGuire & Michael Mara（JCGT 2014）提出的齐次倒数深度 2D DDA 步进 `q_k = q₀ + k·Δq, z_k = 1 / q_k`，无需在每步重乘 4×4 投影矩阵，仅用 1 次加法和 1 次倒数即可在二维像素网格上 100% 保持三维射线的绝对笔直！An original 17-station 3D SSR rangefinder bench compares McGuire homogeneous reciprocal-Z DDA against naive screen-space linear-Z ray bowing.

Scale compliance as α̃ = α / Δt_s² in Δλ = (−C − α̃λ)/(w + α̃). Stop cloth stiffness drifting with FPS & substeps.

为什么在用传统位置动力学（Classic PBD, Müller 2007）制作角色披风布料、绳索吊具或软体肌肉动画时，美术师在 60 FPS（每帧 1 次子步迭代）下好不容易调出一块垂感自然的丝绸（在 `F = 100 N` 拉力与物理柔度 `α = 0.008 m/N` 下伸长 `Δx = 0.8000 m`），一旦放到高刷显示器或为了防穿透把物理子步数提高到 `N_s = 4`（每子步 `Δt_s = Δt / 4`），同一块丝绸就会瞬间变成硬邦邦的钢板，伸长量暴跌 `-93.75%` 到只剩 `0.0500 m`（到 `N_s = 17` 时更是暴跌 `-99.65%` 到 `0.0028 m`）？因为经典 PBD 的无量纲刚度系数没有除以子步时间平方 `Δt_s²`，导致约束修正在每个子步里被重复硬拉！而 Macklin 等人（MIG 2016 / Small Steps 2019）提出的扩展位置动力学（XPBD）从隐式后向欧拉（Implicit Backward Euler）最小化弹性势能出发，引入**时间平方缩放柔度 `α̃ = α / Δt_s²`** 与总拉格朗日乘子累加项 `Δλ = (−C(x) − α̃·λ) / (w + α̃)`：由于 `α̃` 分母中的 `Δt_s²` 与重力运动学预测步 `w·F·Δt_s²` 发生代数级精确抵消，无论物理引擎跑 1 个子步还是 17 个子步、30 FPS 还是 240 FPS，绳索与布料的稳态伸长量恒定锁死在精确的胡克定律解 `Δx = α·F = 0.8000 m`（全 17 站子步刚度漂移严格为 `0.0000 m`），且分母 `w + α̃ > 0` 保证了无限刚度（`α → 0`）下绝对无条件稳定、永不爆炸！An original 17-station 3D tendon dynamometer bench compares Macklin XPBD `Δt_s²`-scaled compliance against unscaled PBD substep stiffening.

Macklin XPBD compliance scaling is not neural cloth simulation / XPBD 物理柔度缩放不等于神经布料仿真推理

This bench evaluates deterministic Macklin, Müller & Chentanez (2016/2019) Extended Position-Based Dynamics (XPBD) time-step invariant compliance (`α̃ = α / Δt_s²`) versus naive unscaled PBD stiffness and 48-iteration Gauss-Seidel relaxation across 17 substep frequencies (N_s ∈ [1, 17]). It does not execute neural cloth surrogate models.

在物理柔度 `α = 0.008 m/N`（刚度 `k = 125 N/m`）、外力负载 `F = 100 N`（真实胡克定律平衡伸长量 `Δx = α·F = 0.8000 m`）跨越 `N_s = 1..17` 个子步时：Macklin XPBD 通过 `α̃ = α / Δt_s²` 在全部 17 个子步站上严格输出 `Δx = 0.8000 m`（`0.0000 m` 子步刚度漂移）；而朴素未缩放 PBD 在第 3 站（`N_s = 4`）处伸长量坍缩至 `0.0500 m`（损失 `-93.75%`，变硬 `16×`），在第 16 站（`N_s = 17`）跌至 `0.0028 m`（损失 `-99.65%`，导致 `16/17` 个子步站失真）！

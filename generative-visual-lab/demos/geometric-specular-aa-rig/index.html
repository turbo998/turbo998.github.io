Widen roughness by pixel normal variance α_AA = √(α₀² + κ²). Stop curved chrome bevels strobing like disco balls.

为什么即便网格完全没有贴任何法线贴图（比如光滑的汽车镀铬窗框、机械装甲倒角或刀刃圆柱面，本征粗糙度 `α₀ = 0.05`），当镜头稍微拉远或缓慢平移仅 `0.40 px`（不到半个像素）时，倒角边缘的高光却会像迪斯科灯球一样发生刺眼的亚像素闪烁（Sub-Pixel Specular Sparkle / Firefly Strobe）？因为在单个屏幕像素内部，弯曲几何体的顶点插值法线已经扫过了 `κ = ∥∂n/∂x∥ = 0.35 rad/px` 的张角！如果片元着色器只在该像素中心点直接拿极其尖锐的原始粗糙度 `α₀ = 0.05` 去计算微表面分布（NDF），那么当亚像素倒角中心恰好落在像素中心（第 8 站 `δ = 0.00 px`）时，亮度会暴冲至 `7.9788`（比像素真实积分亮度高出 `7.07×`）；而当画面仅仅平移 `0.40 px`（第 0 或 16 站 `δ = ±0.40 px`）时，亮度又断崖暴跌至 `0.1583`，产生高达 `50.40×` 的帧间频闪（波及全部 `17/17` 个亚像素相位站）！而 Anton Kaplanyan & Alexey Antonov（HPG 2016，Frostbite 与 Unreal Engine 5 采用）提出的屏幕空间几何曲率高光抗锯齿（Geometric Specular AA），通过将像素内的几何法线方差 `σ_N² = κ² = 0.1225` 叠加进粗糙度平方 `α_AA = √(α₀² + κ²) = 0.3536`，在第 8 站输出守恒亮度 `1.1284` 并在全 17 个亚像素位移站保持 `1.08×` 的丝滑稳定包络！An original 17-station 3D bevel goniophotometer bench compares Kaplanyan curvature-filtered specular AA against naive unfiltered sub-pixel sparkle strobing.

Geometric curvature specular anti-aliasing is not neural video super-resolution / 几何曲率高光抗锯齿不等于神经视频超分推理

This bench evaluates deterministic Anton Kaplanyan & Alexey Antonov (HPG 2016) screen-space normal-variance geometric specular anti-aliasing (α_AA = √(α₀² + κ²)) versus naive unfiltered raw roughness and 64-tap sub-pixel normal-distribution convolution quadrature across 17 sub-pixel drift stations (δ ∈ [−0.40, +0.40] px). It does not execute neural super-resolution or DLSS networks.

在光滑金属倒角本征粗糙度 `α₀ = 0.05`（`α₀² = 0.0025`）、屏幕空间法线曲率 `κ = 0.35 rad/px`（`κ² = 0.1225`）跨越 17 个亚像素相机平移站（`δ ∈ [−0.40, +0.40] px`）时：Kaplanyan 几何曲率高光抗锯齿将滤波粗糙度精确拓宽至 `α_AA = 0.3536`，在第 8 站（`δ = 0.00 px`）输出像素积分守恒亮度 `1.1284`，全 17 站峰谷比仅 `1.08×`（`0` 闪烁伪影）；而朴素未滤波原始粗糙度在第 8 站暴冲至 `7.9788`（`7.07×` 能量爆炸），并在 `δ = ±0.40 px` 暴跌至 `0.1583`，产生高达 `50.40×` 的刺眼亚像素频闪（污染全部 `17/17` 站）！

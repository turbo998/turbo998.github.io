MY TAKE · 选型边界

精确控制有用；逼真外观是另一项工作。

✅ 适合

  • GPU spark, ember, mist, and water-droplet particle systems entering high-drag fluid media
  • Frame-rate independent camera velocity damping and character air-resistance controllers
  • Analytical position integration x_next = x + (v0 / gamma) * (1 - exp(-gamma * dt)) alongside v_next = v0 * exp(-gamma * dt)
  • Unconditionally positive velocity decay immune to frame drops (dt spikes) and high drag coefficients gamma

⛔ 不适合

  • Active thruster propulsion where force is intentionally applied in the reverse direction
  • Static 2D UI layout
  • Unanimated static meshes
  • 1D audio gain sliders

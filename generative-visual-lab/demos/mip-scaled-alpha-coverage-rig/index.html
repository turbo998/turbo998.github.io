Rescale mip alpha contrast around mean ᾱ by 2^L. Stop box-averaged mipmaps making distant trees vanish to 0%.

为什么在开放世界游戏和大规模数字孪生森林场景里，近看枝繁叶茂的松树、灌木丛和铁丝网（覆盖率 `C = 37.50%`，采用 `alpha >= τ = 0.50` Alpha Test 或 Alpha-to-Coverage 渲染），只要镜头往后拉远到 Mipmap 第 2~4 级（`L ∈ [2.0, 4.0]`），整片远山上的树叶就会**像脱发一样迅速变薄、最终在远处凭空变成光秃秃的枝干甚至 100% 完全消失（`C_naive = 0.0000`）**？因为一张平均不透明度 `ᾱ = 0.35`（35% 是针叶 `α = 1`，65% 是天空缝隙 `α = 0`）的树枝贴图，在经过标准 `2×2` 盒式均值滤波生成 Mipmap 时，每一级 Mip 都会把高频波峰向均值 `ᾱ = 0.35` 压平一半（振幅按 `A(L) = A₀·2^(−L)` 指数衰减）！到了第 8 站（`L = 2.00`，即 Mip 2），波峰振幅从 `A₀ = 0.60` 衰减到 `0.15`，整张贴图的最大 Alpha 值 `0.35 + 0.15 = 0.50` 刚好跌破裁剪阈值 `τ = 0.50`——**从 Mip 2 到 Mip 4 的全部 9 个远景站点上，100% 的树叶像素都被 `if (alpha < 0.50) discard` 统统扔掉，树冠覆盖率从 `37.50%` 暴跌至 `0.00%`（波及 `16/17` 个距离站点）**！采用 Ignacio Castaño（2010《The Witness》）提出的保覆盖率 Alpha Mipmap 重缩放（Coverage-Preserving Alpha Mipmaps），按层级还原围绕均值的对比度 `α_corr = ᾱ + (α_mip − ᾱ)·2^L`（或在离线烘焙时用二分搜索反解保覆盖率缩放系数），即可让远景森林从 Mip 0 到 Mip 4 全程死死锁住 `37.50%` 树冠丰满度！An original 17-station 3D canopy densitometer bench compares Castaño coverage-preserving alpha mipmaps against naive box-filtered vanishing foliage.

Coverage-preserving alpha mipmapping is not neural foliage super-resolution / 保覆盖率 Alpha Mipmap 不等于神经植被超分推理

This bench evaluates deterministic Ignacio Castaño (2010 The Witness) coverage-preserving alpha mipmap contrast rescaling (α_corr = ᾱ + (α_mip − ᾱ)·2^L) versus naive box-filtered alpha mipmaps and 54-step bisection coverage threshold search across 17 mipmap stations (L ∈ [0.00, 4.00]). It does not execute neural texture upscaling networks.

在枝叶贴图均值 `ᾱ = 0.35`、初始对比度振幅 `A₀ = 0.60`、裁剪阈值 `τ = 0.50` 跨越 `L ∈ [0.00, 4.00]` 的第 8 站（`Mip L = 2.00`）处：Castaño 保覆盖率重缩放精准锁死树冠覆盖率 `C = 0.3750`（全 17 站与 54 步二分搜索误差低至 `5.55e-17`，`0` 树冠变薄）；而朴素盒式均值滤波将振幅压低至 `0.15`，使 Mip 2 至 Mip 4 共 `9/17` 个远景站点覆盖率彻底归零为 `C_naive = 0.0000`（丢失 `-0.3750` 即 `100%` 树叶，污染全部 `16/17` 个非零 Mip 站点）！

MY TAKE · 选型边界

精确控制有用；逼真外观是另一项工作。

✅ 适合

  • UE5、Unity 与 Three.js 中采用 Alpha Test 或 Alpha-to-Coverage 的树叶、松针、草地、发片与铁丝网
  • 彻底根除远景树木与灌木因 Mipmap 盒式平均把 Alpha 压低到 0.50 以下而导致的秃头消失现象
  • 支持离线烘焙保覆盖率 Mipmap 贴图，或在着色器运行时按 Mip 层级动态放大对比度
  • 与硬件 MSAA Alpha-to-Coverage 或 R2 低差异点画抖动（Round 44）无缝配合

⛔ 不适合

  • 使用标准预乘 Alpha 混合（OVER 算子，守恒量为均值 ᾱ 而非阈值截断面积）的半透明云雾
  • 不含透明镂空通道的纯不透明网格（α ≡ 1.0）
  • 神经纹理超分辨率或生成式植被脑补
  • 禁用 Mipmap 的像素风点采样贴图

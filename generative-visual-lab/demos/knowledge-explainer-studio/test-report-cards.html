MY TAKE · PRODUCTION FIT, GUARDRAILS & READINESS 7 / 7

Best-in-Class for Technical Explainers, Architecture Comparisons & Quant Breakdowns; Not for Character Drama

✅ Good fit (强烈推荐场景)

  • 概念辨析与架构选型 (`xiaozhe-mcp-node-graph`)：如 MCP vs Skill vs Tools、微服务拓扑、协议分层，需三次贝塞尔流光树与焦点聚光降暗。
  • 多步算法与数据流水线 (`xiaozhe-rag-pipeline-flow`)：如 RAG 四阶漏斗、编译器 Pass、CI/CD 门禁，需 `packet-hop-break` 痛点爆破与漏斗筛选动效。
  • 硬核商业与算力经济学 (`chimp-deepseek-unit-economics`)：如 GPU 吞吐量账本、财报拆解、基准评测，需 `counter-seek-safe` 滚动计数器与 8×8 算力砖块矩阵。
  • CI/CD 自动化批量视频生成：零外部 API 密钥依赖，自带 11 道确定性门禁与纯 Python 声学合成。

⛔ Not for (不适用场景)

  • 写实人物表演与口型戏剧：程序化 Canvas/SVG 擅长结构拓扑与量化图表，不替代真人实拍或 Live2D 角色骨肉表演。
  • 超长无结构播客 (>15 分钟纯聊天)：缺乏明确章节拍点与视觉抓手的内容无法发挥 `3.0s` 视觉密度峰值算子的优势。
  • 三维写实流体与物理破碎模拟：重度影视级 3D 粒子/流体特效应交由 Blender / Unreal 管线而非 H5 2D/SVG 渲染器。
  • 跳过 Step 3 风格账本的“盲盒生成”：任何绕过 `style-ledger` 的一键直出都会退化为千篇一律的深蓝紫光 AI 制服感。

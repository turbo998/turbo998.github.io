ORIGINAL / TOKSVIG NORMAL-VARIANCE MIP FILTERING / NO NEURAL DENOISER EXECUTED

Convert mip normal shortening ||n̄|| into roughness σ_n². Stop distant specular fireflies.

为什么一块近看质感细腻的法线贴图金属地板、碳纤维纹理或微凹凸车身，当镜头拉远触发 Mipmap 降采样时，表面会突然变成一片剧烈闪烁、刺眼跳动的“高光萤火虫噪点海（Specular Aliasing / Fireflies）”？因为远景单个像素内包含了朝向 ±35° 交错倾斜的无数微凸起，硬件 Mipmap 对这些法向取平均后，平均法向的长度会缩短为 ||n̄|| = cos(35°) = 0.8192；如果片元着色器直接一句 `normalize(n̄)` 把法向强行拉回单位长度 1.0，同时保持初始低粗糙度 α₀ = 0.15 不变，就等于把粗糙起伏的凹凸表面篡改成了一面光滑如镜的平面，导致高光峰值虚高 10.82×！而 Toksvig 法向方差过滤在归一化前读取缩短长度 r = ||n̄||，将亚像素法向发散度 σ_n² = (1−r)/r 直接累加进粗糙度方差 α_eff² = α₀² + σ_n²。An original 17-station 3D normal-mip goniometer bench compares Toksvig variance-to-roughness filtering against naive mip renormalization fireflies.

r = ||n̄||, σ_n² = (1 − r)/r, α_eff = √(α₀² + σ_n²) → 90.75% specular firefly suppression

Toksvig normal-length variance filtering is not neural spatio-temporal denoising / Toksvig 法向方差过滤不等于神经时空降噪器

This bench evaluates deterministic Toksvig (2005) / Kaplanyan (2016) normal-variance specular anti-aliasing—converting unnormalized mipmapped normal length r = ||n̄|| into effective roughness α_eff = √(α₀² + (1−r)/r)—versus naive mip renormalization across 17 sub-pixel bump tilt angles. It does not execute DLSS Ray Reconstruction or neural temporal denoisers.

在初始粗糙度 α₀ = 0.15、亚像素微凹凸倾角 θ_b = ±35.0° 的第 14 号站点处：Mipmap 线性平均后的未归一化法向模长缩短为 r = ||n̄|| = 0.8192，Toksvig 算子据此提取出亚像素法向方差 σ_n² = (1−r)/r = 0.2208，将有效粗糙度展宽至 α_eff = 0.4932，使 GGX 法线分布峰值平稳回落至 D = 1.3084；而朴素 `normalize(n̄)` 直接丢弃模长 r，锁死 α₀ = 0.15，导致高光峰值虚高至 D = 14.1471（暴涨 10.81×，产生 90.75% 的虚假高光噪点过冲）！

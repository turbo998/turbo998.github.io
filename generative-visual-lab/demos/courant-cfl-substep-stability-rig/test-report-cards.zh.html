MY TAKE · 选型边界

精确控制有用；逼真外观是另一项工作。

✅ 适合

  • Explicit GPU Eulerian fluid, smoke, and shallow-water grid solvers under variable frame delta-time dt
  • Elastic cloth and hair wave propagation where wind gusts spike local wave speed v * dt / dx > 1
  • Adaptive substepping loops N_sub = min(maxSubsteps, ceil(maxCourant)) preventing checkerboard explosion
  • Hybrid integer-cell stencil shift floor(C) + fractional Courant remainder C - floor(C) <= 1

⛔ 不适合

  • Time-independent static mesh rendering without PDE evolution
  • Static 2D UI layout
  • Purely local per-pixel color grading LUTs
  • 1D audio gain sliders

Rotate detail normal n₂ onto base normal n₁ via t = n₁+(0,0,1), r = t·dot(t,u)/t.z − u. Stop UDN flattening.

为什么在给角色皮肤毛孔、岩石微裂纹或汽车风挡雨滴叠加第二层细节法线贴图（Detail Normal Map `n_2`）到宏观基底法线贴图（Base Normal Map `n_1`）上时，如果使用传统的 UDN 水平分量直接相加 `normalize(vec3(n_1.xy + n_2.xy, n_1.z))` 或线性相加 `normalize(n_1 + n_2)`，一旦基底法线本身处于斜坡（`θ_1 = 42.0°`）且细节法线也向同侧倾斜（第 14 站 `θ_2 = +32.0°`，真实旋转叠加后的法线倾角应为 `θ_1 + θ_2 = 74.00°`），UDN 算出来的合成法线就会被硬生生压扁到 `58.21°`（丢失 **`−15.79°` 的法线倾角**，在第 16 站 `θ_2 = +40.0°` 处更是丢失高达 **`−21.53°`**），导致陡峭斜面上的微划痕和毛孔立体感大面积消失？因为细节法线 `n_2` 是相对于平坦切平面朝向 `(0, 0, 1)` 定义的，物理上把它贴到倾斜的宏观法线 `n_1` 上，等价于**执行一次把 `(0, 0, 1)` 旋转到 `n_1` 的最短弧四元数旋转**！而 Barré-Brisebois 与 Hill (2012) 提出的四元数重定向法线贴图（Reoriented Normal Mapping, RNM）利用未归一化半角四元数 `t = n_1 + (0, 0, 1)` 与共轭镜像向量 `u = (−n_2.x, −n_2.y, n_2.z)`，将其化简为仅含 **1 次点积与 1 次标量除法的闭式恒等式 `n_RNM = t · dot(t, u) / t.z − u`**——无需任何三角函数或 `3×3` 矩阵即可天然输出模长恒为 `1.0000` 的精确旋转法线，在全 17 个细节倾角站点上保持 **`0.00°` 角度误差**！An original 17-station 3D detail-normal goniometer bench compares Quaternion RNM against UDN normal flattening.

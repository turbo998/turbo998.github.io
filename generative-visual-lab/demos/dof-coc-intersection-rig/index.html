ORIGINAL / JIMÉNEZ DEPTH-OF-FIELD SAMPLE-COC INTERSECTION RIG / NO NEURAL BOKEH RENDERING EXECUTED

Gate bokeh gather taps by CoC(y) ≥ ∥x − y∥. Stop sharp in-focus characters bleeding halos onto blurry backgrounds.

为什么在许多初级景深（Depth-of-Field, DoF）后处理实现中，当摄像机精确对焦在近处的暗色主角身上（前景位于焦平面 `z_fg = z_focus = 2.0 m`，弥散圆半径 `CoC_fg = 0.0 px`，绝对清晰），而主角身后是失焦虚化的亮色背景散景（`z_bg = 20.0 m`，弥散圆半径 `CoC_bg = 8.0 px`，亮度 `L_bg = 1.0000`）时，清晰主角的外轮廓周围竟然会往背景上渗出一圈8像素宽的脏黑模糊光晕（Sharp-Foreground-on-Blurry-Background Bleed）？因为在外轮廓外侧第 5 号失焦背景像素（`d = +1 px`）上，它自己的弥散圆很大（`CoC_center = 8.0 px`）！如果景深聚集（Gather）着色器直接按 `CoC_center = 8.0 px` 去把周围 16px 内的邻居一视同仁求平均，它就会把左侧 `7.0 px` 宽的对焦前景暗像素（`L_fg = 0.0400`）吸进背景里，算出 `L = 0.5800`（丢失 `−0.4200` 背景散景亮度，污染外侧 `7/17` 个背景像素）！但在真实物理光学中，**位于焦平面上的前景物体弥散圆半径 `CoC(y) = 0.0 px`，它的光线在底片上根本没有扩散，绝对不可能越界糊到旁边的背景像素上**！Jorge Jiménez（SIGGRAPH 2014 Call of Duty，以及 UE5 Diaphragm DoF）提出的采样点弥散圆相交门控 `w(y → x) = H(CoC(y) − ∥x − y∥)`，严格检查每一个采样点 `y` 自己的弥散圆是否够得着当前像素 `x`，将对焦前景的非法渗漏 100% 截断归零，在 `d = +1 .. +12 px` 完整保留 `L_DoF = 1.0000` 的纯净散景！An original 17-station 3D diaphragm optical bench compares Jiménez sample-CoC intersection gating against naive center-CoC foreground halo bleeding.

Sample-CoC intersection gating is not neural bokeh rendering / 弥散圆相交门控不等于神经散景合成推理

This bench evaluates deterministic Jorge Jiménez (SIGGRAPH 2014) / Unreal Engine 5 Diaphragm Depth-of-Field sample-CoC intersection gating (w(y → x) = H(CoC(y) − |x − y|)) versus naive center-CoC gathering and 64-tap bokeh gather quadrature across 17 silhouette boundary pixels (d ∈ [−4, +12] px). It does not execute neural portrait bokeh networks.

在对焦清晰的前景暗色物体（第 0~4 站 `d = −4 .. 0 px`，`CoC_fg = 0.0 px`，`L_fg = 0.0400`）与失焦背景散景（第 5~16 站 `d = +1 .. +12 px`，`CoC_bg = 8.0 px`，`L_bg = 1.0000`）交界外侧的第 5 站（`d = +1 px`）处：Jiménez 采样点弥散圆相交门控因检测到前景点 `CoC(y) = 0.0 px < |x − y|` 将其权重严格归零，锁死纯净背景散景 `L_DoF = 1.0000`（全 17 站 `0` 光晕渗漏）；而朴素中心弥散圆聚集盲目按 `CoC_center = 8.0 px` 混入 7 像素宽的前景暗色，将背景散景拉暗至 `0.5800`（产生 `−0.4200` 脏黑光晕，污染 `7/17` 个背景站点）！

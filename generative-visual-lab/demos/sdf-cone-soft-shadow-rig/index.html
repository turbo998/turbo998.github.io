Track closest cone ratio min(k · d_SDF / t) along 1 ray. Stop sphere-traced shadows cutting hard binary edges.

为什么在有向距离场（Signed Distance Field, SDF）光线步进与 UE5 距离场软阴影（Distance Field Soft Shadows）中，我们不需要像传统蒙特卡洛路径追踪那样朝太阳圆盘发射 64 条分布式阴影射线，**仅仅发射 1 条主光线就能免费算出“离遮挡物越近越锐利、离遮挡物越远越柔和”的面积光真实物理半影（Area-Light Penumbra）**？因为 SDF 在步进途中的每一个点 `P + t·L` 上，返回的值 `d_SDF` 本身就是以该点为球心、**绝对不会碰到任何遮挡物的最大安全球半径**！这意味着：在步进距离 `t` 处，这颗安全球对受光点张开的可见圆锥半角正切值正好是 `d_SDF / t`！如果在球追踪循环中像朴素二值步进那样只判断“有没有撞上物体（`d_min <= 0 ? 0 : 1`）”，在距离遮挡物 `t_occ = 4.0 m`、光源柔和度 `k = 4.0`（物理半影半宽 `w = t/k = 1.0 m`）的地面上，原本宽达 `2.0 m`（跨越第 4 站至第 12 站 `d_min ∈ [−0.80, +0.80] m`）的丝滑半影过渡带会被一刀砍成非黑即白的硬阶跃——**在第 8 站几何边界（`d_min = 0.00 m`，太阳圆盘刚好被挡住一半 `S_cone = 0.5000`）处直接硬切为 `0.0000`（误差 `0.5000`），在第 7 站与第 9 站分别产生 `−0.3520` 与 `+0.3520` 的本影/光亮截断误差，污染全部 `9/17` 个半影站点**！采用 Inigo Quilez 与 Daniel Wright（SIGGRAPH 2015 UE4/UE5）推广的锥比软阴影公式 `u = clamp(0.5 + 0.5·k·d_min/t, 0, 1), S = u²(3 − 2u)`，单条射线即可完美复刻 64 射线面积光求积！An original 17-station 3D penumbra photometer bench compares Quilez/Wright SDF cone-ratio soft shadows against naive hard binary sphere-tracing.

SDF cone-traced soft shadows are not neural shadow denoising / 距离场锥追踪软阴影不等于神经阴影去噪推理

This bench evaluates deterministic Inigo Quilez & Daniel Wright (SIGGRAPH 2015 UE4/UE5 Distance Field Soft Shadows) single-ray cone-aperture penumbra integration (u = clamp(0.5 + 0.5·k·d_min/t, 0, 1), S = u²(3 − 2u)) versus naive binary sphere-traced hard shadows (d_min > 0 ? 1 : 0) and 64-ray distributed area-light disk quadrature across 17 closest-approach stations (d_min ∈ [−1.60 m, +1.60 m]). It does not execute neural spatiotemporal shadow denoisers.

在遮挡物距离 `t_occ = 4.0 m`、光源柔和度 `k = 4.0`、最近擦掠距离跨越 `d_min ∈ [−1.60 m, +1.60 m]` 的第 8 站几何边界（`d_min = 0.00 m`）处：Quilez/Wright 距离场锥比积分通过单条射线精准还原半遮挡太阳圆盘可见度 `S_cone = 0.5000`（在第 6 站 `−0.40 m` 输出 `0.2160`、第 10 站 `+0.40 m` 输出 `0.7840`，全 17 站与 64 射线分布式面积光求积误差低至 `1.11e-16`，`0` 刀切硬边）；而朴素二值球追踪在 `d_min = 0.00 m` 处硬切为 `0.0000`（峰值误差 `0.5000`，第 7/9 站误差 `0.3520`），将全部 `9/17` 个半影站点砍成死板方波！

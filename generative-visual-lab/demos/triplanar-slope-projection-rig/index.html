Project cliffs across 3 orthogonal planes: N_x² + N_y² + N_z² = 1. Stop top-down UVs stretching 11.5× on cliffs.

为什么在开放世界地形、体素洞穴（Marching Cubes）和数字孪生峡谷中，如果你直接拿世界水平坐标做顶视平面纹理映射（Top-Down Planar UV `uv = worldPos.xz`），平缓草地上的岩石纹理很清晰，可一旦到了陡峭的悬崖峭壁（第 15 站 `θ = 80°` 和第 16 站 `θ = 85°`），整面山崖上的贴图就会被**纵向拉扯成一条条像瀑布面条一样模糊的垂直拉丝条纹（Vertical UV Streak Stretching）**？因为当悬崖表面倾斜角为 `θ` 时，沿着山坡向上走 `1 m` 弧长，它在水平 `XZ` 平面上的投影只前进了 `ΔX = cos θ = N_y m`！在 `θ = 80°` 悬崖处，纹素采样密度坍塌到 `D_planar(80°) = cos 80° = 0.1736`（**丢失 `-82.64%` 细节，每个纹素被纵向硬拉长 `5.76×`；在 `85°` 绝壁处密度仅剩 `0.0872`，纵向拉长 `11.47×`，污染 `15/17` 个斜坡站点**）！采用 Ryan Geiss（NVIDIA GPU Gems 3, 2007）提出的三平面正交世界投影（Triplanar Projection Mapping），同时沿水平面 `XZ`（斜坡采样率 `cos θ`）与侧立面 `YZ/XY`（斜坡采样率 `sin θ`）采样并按法线分量 `N_y = cos θ, N_x = sin θ` 加权合成，由勾股恒等式 `D_tri = D₀·(N_y·cos θ + N_x·sin θ) = D₀·(cos²θ + sin²θ) ≡ 1.0000`，无需手工展 UV 即可在 `0°~90°` 任意悬崖绝壁上锁死 `100%` 恒定纹素密度！An original 17-station 3D cliff pantograph bench compares Geiss conformal triplanar projection against naive top-down planar XZ cliff stretching.

Triplanar projection is not neural texture inpainting / 三平面正交投影不等于神经纹理修补推理

This bench evaluates deterministic Ryan Geiss (NVIDIA GPU Gems 3, 2007) conformal triplanar world-space projection (D_tri = D₀·(N_x² + N_y² + N_z²)) versus naive top-down planar XZ projection (D_planar = D₀·cos θ) and 64-step 3D cliff arc-length parametric quadrature across 17 cliff slope angle stations (θ ∈ [5°, 85°]). It does not execute neural texture synthesis networks.

在目标纹素密度 `D₀ = 1.0000`、山崖倾角跨越 `θ ∈ [5°, 85°]` 的第 15 站陡峭悬崖（`θ = 80°`）处：Geiss 三平面正交投影由侧向 `YZ` 平面（权重 `N_x = 0.9848`）与顶面 `XZ` 平面（权重 `N_y = 0.1736`）正交互补，严格锁定纹素采样密度 `D_tri = 1.0000`（全 17 站与 64 步弧长参数数值求积误差低至 `3.33e-16`，`0` 悬崖拉丝）；而朴素顶视平面投影在 `80°` 处坍缩至 `D_planar = 0.1736`（丢失 `-82.64%` 密度，拉长 `5.76×`），在 `85°` 处跌至 `0.0872`（丢失 `-91.28%`，拉长 `11.47×`），污染 `15/17` 个斜坡站点！

ORIGINAL / KOPF JOINT BILATERAL DEPTH UPSAMPLE RIG / NO NEURAL DEPTH INPAINTING EXECUTED

Gate half-res volumetric taps by full-res depth exp(−Δz²/2σ_z²). Stop bilinear upsampling leaking glowing fog halos onto dark silhouettes.

为什么在许多实时体积雾（Volumetric Fog）、体积云和环境光遮蔽（SSAO）管线中，为了节省 75% 的光线步进开销而采用半分辨率（Half-Resolution）渲染后，一旦用硬件双线性过滤（`texture(halfResTex, uv)`）放大回全分辨率，近处暗色角色或立柱（`z_fg = 2.0 m`，体积雾亮度 `L_fg = 0.0500`）站在远处亮色丁达尔体积光背景（`z_bg = 25.0 m`，体积雾亮度 `L_bg = 0.9500`）前时，角色边缘一圈会冒出刺眼的半透明发光白边（Silhouette Halo Bleed）？因为在第 8 号全分辨率前景轮廓像素（`z_hi = 2.0 m`，位于前景低分采样点 `A` 与背景低分采样点 `B` 的双线性中点 `u = 0.50`）处，朴素硬件双线性插值完全无视 `2.0 m → 25.0 m` 的 23 米深度断崖，把 50% 的背景亮雾强行糊到了近处暗色立柱上，输出 `L = 0.5000`（比真实前景雾 `0.0500` 暴增 `10.00×`，产生 `+0.4500` 光晕渗漏并污染 `7/17` 个边界像素）！而 Johannes Kopf 等人（SIGGRAPH 2007）提出的联合双边上采样（Joint Bilateral Upsampling, JBU），利用现成的全分辨率深度缓冲 `z_hi` 乘以深度亲和权重 `exp(−(z_hi − z_lo)² / 2σ_z²)`，将跨深度断崖的异侧采样点权重精确压零，在全 17 个像素站完美恢复刀锋般锐利的全分辨率体积雾边缘（`0/17` 光晕渗漏），且比全分辨率 64 步光线步进快数十倍！An original 17-station 3D bilateral densitometer bench compares Kopf joint bilateral depth-guided upsampling against naive bilinear silhouette halo bleeding.

Joint bilateral depth upsampling is not neural depth inpainting / 联合双边高分深度引导上采样不等于神经深度补全推理

This bench evaluates deterministic Johannes Kopf et al. (SIGGRAPH 2007) Joint Bilateral Upsampling (JBU) using full-resolution G-buffer depth range weights versus naive hardware bilinear interpolation and full-resolution 64-step volumetric Beer-Lambert ray marching across 17 full-resolution silhouette boundary pixels. It does not execute neural depth inpainting or AI super-resolution networks.

在近景暗色立柱（`z_fg = 2.0 m`，`L_fg = 0.0500`，第 0~8 站）与远景亮色丁达尔体积雾（`z_bg = 25.0 m`，`L_bg = 0.9500`，第 9~16 站）交界的第 8 站前景边缘（双线性坐标 `u = 0.50`）处：Kopf 联合双边上采样（`σ_z = 0.50 m`）因检测到背景采样点 `Δz = 23.0 m` 的深度断崖将其权重归零，严格锁定前景真实亮度 `L_vol = 0.0500`（全 17 站 `0` 光晕渗漏）；而朴素硬件双线性上采样盲目混合 50% 背景亮雾，输出 `0.5000`（产生 `+0.4500` 即 `10.00×` 发光白边过冲，污染全部 `7/17` 个跨界过渡站点）！

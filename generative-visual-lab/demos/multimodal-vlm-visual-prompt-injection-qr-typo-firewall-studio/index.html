架构师选型总结：永远把外部图片、PDF 与网页像素当作“不可信代码输入”

✅ 强烈推荐部署本防火墙的场景 (Good fit)
  • 财务 AP 发票审核、理赔单据核验、HR 简历筛选与合同多模态 RAG 管线
  • 具备点击、填表与命令执行权限的 Computer-Use / 浏览器自动化智能体
  • 跨境电商与内容平台的千万级商品图片违禁品及隐藏二维码自动化风控
⛔ 严禁直接裸跑的单模型架构 (Not for)
  • 严禁让同一个多模态大模型既直接读取外部未清洗图片、又拥有高危 API 调用权
  • 严禁误以为“部署了纯文本 Prompt 敏感词过滤”就能防御图片内的视觉提示词注入

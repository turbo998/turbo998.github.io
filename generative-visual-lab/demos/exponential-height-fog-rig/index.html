Integrate exponential fog along the ray (1 − e^(−kΔh)) / (kΔh). Stop valley mist burying high mountain peaks.

为什么在许多户外地形与山谷开放世界场景中，当摄像机站在低洼的河谷雾气里（`h_cam = 0 m`，谷底消光系数 `σ₀ = 0.015 m⁻¹`，衰减系数 `k = 0.02 m⁻¹` 即标高 `50 m`）抬头仰望斜距 `L = 200 m`、海拔高达 `h_target = 240 m` 的雪山山顶时，高耸入云的山峰非但没有穿透薄雾露出清晰壮丽的山脊，反而跟谷底的石头一样被死死淹没在 `95.02%` 的浓白雾墙里（`T_naive = exp(−0.015 × 200) = 0.0498`）？因为朴素的距离雾着色器直接拿**摄像机所在谷底的局部雾浓度 `σ(h_cam)` 乘以视线总长度 `L`**，错误地假设整条斜向天空的 200 米视线上全都充满着谷底浓雾！而 Carsten Wenzel（SIGGRAPH 2006 CryEngine，现为 Unreal Engine 5 `ExponentialHeightFog` 与 Unity HDRP 标准）推导的闭式指数高度雾线积分公式 `τ = σ₀ · e^(−k·h_cam) · L · (1 − e^(−k·Δh)) / (k·Δh)`，对视线穿过不同海拔高度时的指数稀薄过程精确求取原函数：在仰望第 16 站（`h = 240 m`，`k·Δh = 4.80`）时，线积分衰减因子为 `(1 − e^(−4.80)) / 4.80 = 0.2066`，将光学厚度从 `3.0000` 精准收敛至 `0.6199`，保留高达 `T_fog = 0.5380`（`53.80%`）的通透山巅可见度（比谷底外推法高出 `10.81×`，消除 `−0.4882` 雾墙白化损失）！An original 17-station 3D mountain transmissometer bench compares Wenzel closed-form exponential height-fog line integration against naive camera-altitude density extrapolation.

Closed-form height-fog line integration is not neural image dehazing / 闭式高度雾线积分不等于神经图像去雾推理

This bench evaluates deterministic Carsten Wenzel (SIGGRAPH 2006) closed-form exponential height-fog ray line integration (τ = σ₀ · L · (1 − exp(−kΔh)) / (kΔh)) versus naive camera-altitude constant-density extrapolation and 64-step Beer-Lambert ray-marching cascade across 17 mountain elevation stations (h ∈ [0, 240] m). It does not execute neural single-image dehazing networks.

在谷底雾浓度 `σ₀ = 0.015 m⁻¹`、海拔衰减率 `k = 0.02 m⁻¹`（标高 `H = 50 m`）、斜距 `L = 200 m` 的第 16 站山巅（`h = 240 m`）处：Wenzel 闭式线积分精确捕获雾气随海拔升高迅速稀薄的物理过程，输出 `τ = 0.6199` 与 `T_fog = 0.5380`（全 17 站 `0` 雾墙白化伪影）；而朴素相机高度密度外推恒定使用谷底密度算出 `τ = 3.0000` 与 `T_naive = 0.0498`（在山顶丢失 `−0.4882` 即 `90.75%` 的山体可见度，污染第 1~16 站共 `16/17` 个高海拔站点）！

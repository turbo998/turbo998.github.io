Sort shared edge endpoints & apply Top-Left tie-breaking. Stop triangle seam leaks.

为什么在光线追踪网格求交、软光栅化器或纹理烘焙管线中，两个严丝合缝共享同一条对角边 V₁V₂ 的相邻三角形 T_A = (V₀, V₁, V₂) 和 T_B = (V₃, V₂, V₁)，在接缝处经常会漏出一串 1 像素宽的背景亮孔（“共边漏光裂缝 Seam Crack”），或者在半透明网格上把接缝像素重复画两遍（“接缝重绘亮线 Seam Overdraw”）？因为首先在浮点数里分别以 V₁ 和 V₂ 为原点算 `(P − V₁)×(V₂ − V₁)` 与 `(P − V₂)×(V₁ − V₂)` 会因减法顺序不同产生正负号不一致；其次当点恰好落在共边上（e = 0）时，用 `e > 0` 会被两个三角形同时丢弃（0 次命中），用 `e >= 0` 又会被两个三角形同时抢走（2 次命中）！而水密（Watertight）规范化边函数先对共边端点按字典序排序保证 `e_BA(P) ≡ −e_AB(P)`，再配合顶左填充决胜规则（Top-Left Tie-Breaking Rule：dy > 0 或 dy == 0 && dx < 0），确保接缝上每一个点在全网格中恒定只命中唯一 1 个三角形！An original 17-station 3D shared-seam rasterizer bench compares watertight canonical Top-Left edge functions against naive seam cracks.

Watertight edge-function tie-breaking is not neural surface reconstruction / 水密边函数共边决胜不等于神经曲面重建

This bench evaluates deterministic Pineda (1988) / Woop (2013) watertight barycentric edge functions with canonical sorted-endpoint evaluation and Top-Left tie-breaking versus naive strict interior testing across 17 quad stations (11 shared-seam points + 6 interior points). It does not execute NeuS, SuGaR, or neural implicit mesh extractors.

在共边四边网格（半宽 W = 2.0 u，对角斜率 k = 1.0）的 17 个采样站点（含对角共边 V₁V₂ 上的 11 个精确共线点与两侧内部的 6 个点）中：水密规范化顶左规则（Watertight Canonical Top-Left）在全部 17 个站点上严格保持唯一命中数 hits ≡ 1（漏光裂缝 0 处，重复绘制 0 处，重心坐标和 Σλ ≡ 1.000000）；而朴素严格内部判据（e > 0）导致共边上的全部 11 个采样点在两个三角形上同时被拒（hits = 0，产生 11/17 处对角漏光裂缝）！

MY TAKE

Exact controls are useful; realism remains a separate job.

✅ Good fit

  • Specular Manifold Sampling (SMS) and Manifold Next-Event Estimation (MNEE) for underwater caustics
  • Time-of-Flight (ToF) transient rendering and LiDAR optical path length (OPL) accumulation across dielectrics
  • Apparent depth and refractive shadow-ray bending between underwater receivers and above-water lights
  • Enforcing stationary phase d(n1*d1 + n2*d2)/dx = 0 so Huygens wavelets interfere constructively

⛔ Not for

  • Homogeneous vacuum ray casting with uniform refractive index n1 === n2 === 1.0
  • Static 2D UI layout
  • Unlit wireframe geometry
  • 1D audio gain sliders

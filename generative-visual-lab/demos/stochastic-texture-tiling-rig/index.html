Divide hex-cell blends by √(w₁² + w₂² + w₃²). Stop linear barycentric tiling washing out −42.3% contrast at vertices.

为什么在大面积开放世界草地、砂石路面或混凝土地面渲染中，为了打破普通重复贴图 `fract(uv)` 刺眼的“麻将席网格重复感（Wallpaper Grid Repetition）”，当我们把地面划分成三角/六边形单纯形网格（Simplex/Hex Grid）、给每个格点随机偏移 UV 并用重心坐标 `w₁ + w₂ + w₃ = 1` 混合 3 个相邻随机图块 `C_linear = w₁C₁ + w₂C₂ + w₃C₃` 时，虽然大网格消失了，但每个六边形交界处都会浮现出一团团**像被水洗掉色一样模糊发灰的“低对比度泥斑（Barycentric Contrast Washout / Ghost Blobs）”**？因为根据概率论，三个独立同分布（方差均为 `σ₀²`）的随机图块按权重 `(w₁, w₂, w₃)` 线性相加后，均值虽然守恒（`(w₁+w₂+w₃)c̄ = c̄`），但**方差会缩水为 `Var(C_linear) = (w₁² + w₂² + w₃²)·σ₀²`，标准差（对比度振幅）缩水为 `σ_linear = √(w₁² + w₂² + w₃²)·σ₀`**！在 3 个格点交汇的重心正中央（第 8 站 `u = 0.50, w₁ = w₂ = w₃ = 1/3`）处，欧氏模长跌至谷底 `∥w∥₂ = √(1/9 + 1/9 + 1/9) = 1/√3 ≈ 0.5774`——**导致交界处的纹理对比度暴跌 `−42.26%`（方差暴跌 `−66.67%`），使全部 `15/17` 个内部过渡站点出现肉眼可见的周期性模糊灰斑**！采用 Eric Heitz & Fabrice Neyret（2018）与 Deliot & Heitz（HPG 2019）提出的保方差重心归一化 `C_Heitz = c̄ + Σ w_k(C_k − c̄) / √(w₁² + w₂² + w₃²)`，即可在全 17 个过渡站点 100% 锁死满血对比度 `σ = 1.0000`！An original 17-station 3D hex-simplex densitometer bench compares Heitz variance-preserving stochastic texture tiling against naive linear barycentric contrast washout.

Variance-preserving stochastic tiling is not neural texture synthesis / 保方差随机六边形平铺不等于神经纹理扩散生成推理

This bench evaluates deterministic Eric Heitz & Fabrice Neyret (2018) / Thomas Deliot & Eric Heitz (HPG 2019) variance-preserving barycentric stochastic texture tiling (C = c̄ + Σ w_k(C_k − c̄) / √(w₁² + w₂² + w₃²)) versus naive linear barycentric blending (Σ w_k C_k) and 64-node orthogonal harmonic spatial patch variance integration across 17 simplex transition stations (u ∈ [0.00, 1.00]). It does not execute neural diffusion texture synthesis networks.

在基准纹理对比度标准差 `σ₀ = 1.0000`、跨越六边形/三角形单纯形从格心（`u = 0.00, w = (1,0,0)`）经三格交汇中心（第 8 站 `u = 0.50, w = (1/3,1/3,1/3)`）到对边（`u = 1.00`）的 17 个站点上：Heitz 保方差归一化通过除以欧氏权重范数 `∥w∥₂ = 1/√3 = 0.5774`，在全 17 站严格锁死输出对比度标准差 `σ = 1.0000`（与 64 节点正交空间块方差积分误差低至 `2.22e-16`，`0` 模糊泥斑）；而朴素线性重心混合在第 8 站三交点处将对比度压缩至 `σ_naive = 0.5774`（丢失 `−0.4226` 即 `−42.26%` 对比度振幅与 `−66.67%` 方差，污染全部 `15/17` 个内部过渡站点）！

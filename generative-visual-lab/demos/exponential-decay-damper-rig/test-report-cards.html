MY TAKE

Exact controls are useful; realism remains a separate job.

✅ Good fit

  • Smooth camera follow, UI value interpolation, audio/exposure adaptation, and turret tracking across variable 30Hz–240Hz displays
  • Preventing single-frame shader-compile or GC hitches (λ·Δt > 1) from flinging the camera past the target (+11.35m overshoot)
  • Exact semigroup invariance: splitting any interval Δt into N arbitrary substeps produces the exact same final state
  • Replacing fixed-step RK4 sub-stepping loops for first-order linear relaxation systems

⛔ Not for

  • Second-order spring-mass systems requiring intentional momentum overshoot and oscillation (use analytical underdamped springs)
  • Constant-speed linear motion (moveTowards(x, target, speed * dt)) where velocity is constant rather than proportional to distance
  • Neural video frame interpolation or optical-flow gimbal stabilization
  • Static snapped transforms with λ → ∞

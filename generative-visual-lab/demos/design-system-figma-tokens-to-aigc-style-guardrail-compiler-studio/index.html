架构师选型总结：用 W3C Design Tokens 作为企业生成式视觉的“唯一真实源（SSOT）”

✅ 强烈推荐采用本编译架构的场景 (Good fit)
  • SaaS 软件、金融 App 与消费电子品牌的季度功能发布海报及 UI 动效演示片
  • 需要严格统一透视倾角、材质球与品牌主色的百款 3D 等轴测图标集生产
  • 强制要求 WCAG 2.2 AAA 无障碍对比度与 Light/Dark 双模同步派生的政企应用
⛔ 严禁直接裸跑自然语言 Prompt 的场景 (Not for)
  • 严禁把 `#Hex` 品牌色号作为纯文本写进 Prompt 指望扩散模型精准还原
  • 严禁让图像/视频扩散模型直接生成带真实产品 UI 按钮、表格与字体排版的截图

MY TAKE · 选型边界

精确控制有用；逼真外观是另一项工作。

✅ 适合

  • Executive CTO Cloud & AI architecture interactive sandboxes, RAG/Agentic dataflow explainers, and product launch scrollytelling landing pages
  • Combining Isometric SVG vector topology (crisp 4K text, ARIA accessibility, SEO, click-to-inspect) with viewport-culled Canvas 2D packet streams and Rive state machines
  • Delivering < 50KB First Contentful Paint (FCP) and locked 60fps smoothness across desktop projectors and 390px mobile viewports

⛔ 不适合

  • Photorealistic open-world AAA 3D game environments with millions of deforming polygons
  • Static PDF printouts with zero interactivity
  • Unculled DOM node trees exceeding 10,000 synchronous layout reads per scroll tick

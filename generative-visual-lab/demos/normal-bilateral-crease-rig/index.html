为什么在对屏幕空间全局光照（SSGI）、环境光遮蔽（SSAO/GTAO）或光线追踪漫反射做空间双边滤波去噪（Spatial Bilateral Denoising）时，如果只使用深度亲和权重 `w_z = exp(−Δz² / 2σ_z²)`，物体与远景天空的轮廓边缘很干净，可一旦到了**室内墙面与地板交汇的 90° 墙角折痕（Crease）或立方体盒子的直角棱边**，背光地面的暗黑阴影就会越过棱线糊到受光墙面上（把锋利的立方体棱角涂成一团脏乎乎的圆角黑边）？因为**在两面相交的 90° 墙角折痕处，墙面与地板在三维空间里是无缝相连的，深度差 `Δz ≡ 0.00 m`（深度完全连续）**！仅看深度的双边滤波器在墙角处算出的深度权重 `w_z = exp(0) = 1.0000`，完全是个“睁眼瞎”！当半径 `R = 4 px` 的滤波核扫过第 8 站受光墙角边缘（`d = 0 px`，真实受光墙面照度 `E_wall = 0.9600`，相邻背光地面照度 `E_floor = 0.1600`）时，仅深度滤波器会把地面与墙面强行平均，将受光墙角照度拉暗至 `E_naive = 0.6100`（**丢失 `−0.3500` 即 `36.46%` 棱角亮度，污染折痕两侧 `8/17` 个站点**）！采用交叉双边法线截断核 `w_N(p, q) = max(0, N_p · N_q)^32`，利用墙面法线 `N_wall = (1,0,0)` 与地面法线 `N_floor = (0,1,0)` 的正交性 `N_p · N_q = 0`，在 `Δz = 0` 的连续折痕处将跨平面权重精确归零，100% 锁死锋利如刀的 90° 立方体明暗交界线！An original 17-station 3D crease microdensitometer bench compares cross-bilateral normal-stopping filters against naive depth-only bilateral corner smearing.

Cross-bilateral normal-stopping is not a neural GI denoiser / 交叉双边法线截断不等于神经全局光照去噪推理

This bench evaluates deterministic Sloan/Kopf/SVGF cross-bilateral normal-stopping spatial filtering (w_N(p, q) = max(0, N_p · N_q)^32) versus naive depth-only bilateral filtering (Δz = 0 → w_z = 1) and 64-tap spherical normal-angle kernel integration across 17 pixel stations (d ∈ [−8 px, +8 px]) spanning a 90° continuous-depth wall-floor crease. It does not execute neural denoising networks.

在滤波半径 `R = 4 px`、背光地面照度 `E_floor = 0.1600`、受光墙面照度 `E_wall = 0.9600` 相交于深度连续（`Δz = 0.00 m`）的 90° 直角折痕第 8 站（`d = 0 px`）处：交叉双边法线门控利用 `N_floor · N_wall = 0` 将跨平面采样权重严格置零，锁定受光墙角 `E = 0.9600`（全 17 站与 64 抽头球面角向核积分误差为 `0.0000`，`0` 棱角晕染）；而朴素仅深度双边滤波因 `Δz = 0` 完全失明，将第 8 站拉暗至 `E_naive = 0.6100`（丢失 `−0.3500` 即 `36.46%` 亮度，污染折痕两侧 `8/17` 个站点）！

为什么在实时游戏和 3D 数字孪生场景里，用朝向相机的二维广告牌（2D Billboard Quad）渲染贴地浓烟、爆炸火球、瀑布水雾或车轮扬尘时，只要镜头稍微转动，烟雾团与地面斜坡或墙面相交的地方就会露出一条**像刀切硬纸板一样锋利、出戏的二维平面交界硬切痕（Hard Billboard Intersection Seam）**？因为一团在视觉上看起来有 `d_fade = 0.80 m` 厚的烟雾粒子，在几何上其实只是一张厚度为 `0` 的二维薄片！如果仅靠硬件深度缓冲测试（Hard Z-Test `z_particle <= z_scene`），在薄片位于地面后方（`Δz = z_scene − z_particle < 0`）时透明度为 `0`，而一旦跨过交界线（第 4 站 `Δz = 0.00 m` 及第 6 站 `Δz = +0.20 m`），透明度瞬间从 `0.0000` 阶跃跳变到满额 `α₀ = 0.8000`——**在第 4 站制造 `+0.8000` 悬崖切痕，在第 6 站（仅 `0.20 m` 浅薄雾层）比真实体积积分密度 `0.1250` 虚高 `+0.6750`（`6.40×`），导致整个 `0.80 m` 过渡带内的 `8/17` 个站点暴露出纸片插地伪影**！采用 Tristan Lorach（NVIDIA GPU Gems 3, 2007 / UE5 `DepthFade`）提出的软粒子三阶埃尔米特深度消隐（Soft Particle Hermite Depth-Fade），读取场景线性深度 `z_scene` 计算归一化间隙 `s = clamp((z_scene − z_particle) / d_fade, 0, 1)` 并乘以 `s²(3 − 2s)`，即可在交界处实现零值且零梯度的 `C¹` 丝滑消隐！An original 17-station 3D particle densitometer bench compares Lorach Hermite depth-fade soft particles against naive hard Z-test billboard clipping.

Soft particle depth-fade is not neural volumetric splatting / 软粒子深度消隐不等于神经体积高斯溅射推理

This bench evaluates deterministic Tristan Lorach (NVIDIA GPU Gems 3, 2007) cubic Hermite soft particle depth-fade (α_soft = α₀·s²(3 − 2s), s = clamp((z_scene − z_particle)/d_fade, 0, 1)) versus naive hardware Z-test billboard clipping (H(z_scene − z_particle)) and 64-slab volumetric parabolic density quadrature across 17 depth-clearance stations (Δz ∈ [−0.40 m, +1.20 m]). It does not execute neural volumetric rendering networks.

在基础不透明度 `α₀ = 0.80`、体积消隐厚度 `d_fade = 0.80 m`、深度间隙跨越 `Δz ∈ [−0.40 m, +1.20 m]` 的第 6 站浅薄交界区（`Δz = +0.20 m, s = 0.25`）处：Lorach 软粒子深度消隐闭式积分输出柔顺羽化值 `α_soft = 0.1250`（在第 4 站 `Δz = 0.00 m` 处精确归零且一阶导数为零，全 17 站与 64 层体积密度数值求积误差低至 `1.11e-16`，`0` 纸板切边）；而朴素硬件深度测试在 `Δz ≥ 0` 时瞬间跳变至 `α_hard = 0.8000`（在第 4 站突跳 `+0.8000`，在第 6 站虚高 `+0.6750` 即 `6.40×`，污染全部 `8/17` 个过渡带站点）！

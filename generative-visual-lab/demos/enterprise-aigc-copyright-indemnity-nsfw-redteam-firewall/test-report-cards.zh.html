MY TAKE · 选型边界

精确控制有用；逼真外观是另一项工作。

✅ 适合

  • Public-facing consumer AIGC campaigns (WeChat Mini-Program custom packaging, interactive mall LED booths, game avatar generators)
  • Blocking visual shape metaphors ("red-white-blue yin-yang circle"), ControlNet QR/squint-text steganography, and unauthorized celebrity likenesses
  • Preserving enterprise cloud IP Indemnification (Azure Customer Copyright Commitment / Google Vertex / Adobe Firefly) via immutable WORM audit logs

⛔ 不适合

  • Relying solely on regex text blocklists for public image/video generators (easily bypassed by shape descriptions and poisoned reference images)
  • Disabling cloud vendor mandatory safety filters without a compensating verified guardrail (voids copyright indemnification)
  • Offline air-gapped scientific simulations with zero user input

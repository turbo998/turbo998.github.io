4 / 7 · UNDER THE HOOD

Internal FSQ(dim=512, s=9) anchor + asymmetric 16k->48k AudioVAE contract

Top: audited forward/streaming invariants in voxcpm2.py & audiovae_v2.py. Bottom: deterministic 1024-pt Welch PSD verifier output.

# src/voxcpm/model/voxcpm2.py (lines 258, 345, 667) & audiovae_v2.py
ref_wave_16k = torchaudio.functional.resample(ref_wav, orig_sr, 16000)
z_25hz       = audio_vae_v2.encode(ref_wave_16k)          # hop=640 -> 25 Hz, dim=64
patches      = patchify(z_25hz, patch_size=4)             # 6.25 Hz (160 ms / step)
seq_input    = concat([103, loc_enc(ref_patches), 104], text_tokens)

h_tslm       = base_lm_28L(seq_input)
h_fsq        = torch.round(torch.tanh(proj(h_tslm)) * 9) / 9  # Internal FSQ(512, s=9)
h_ralm       = residual_lm_8L(h_fsq + loc_enc_unquantized_bypass)
pred_patch   = loc_dit.sample_cfm(h_ralm, steps=10, cfg_value=2.0)
pcm_48k      = streaming_vae_decoder.decode(pred_patch)   # strides [8,6,5,2,2,2]=1920 -> 48 kHz
if streaming: retry_badcase = False                       # Anti-babble retry disabled in stream!

7 / 7 · MY TAKE

Self-host VoxCPM2 above 25M chars/mo for cloning; keep Azure Speech for SLA & visemes

Production recommendation: deploy a Hybrid Dual-Track Speech Router pairing vLLM-Omni GPU pools with Azure AI Speech.

PASSGood fit
  • Expressive audiobooks, podcasts & game NPCs: native 48 kHz output (17.7 kHz BW) preserves whispers, sobs, laughter, and 9 Chinese dialects.
  • Private voice IP cloning under clean Apache-2.0 weights: #1 speaker similarity in 22/24 languages plus 5-10 min LoRA adaptation.
  • SEA multilingual localization: 1.42% Burmese, 1.90% Lao, and 2.05% Khmer CER where competing open models fail (75%-87%).
  • High-volume TCO optimization (>25M chars/mo): cuts unit cost 60%-85% vs cloud HD ($12.8k/mo Azure HD vs ~$3.2k/mo GPU cluster @ 850M chars/mo).
BOUNDARYNot for
  • Regulated banking, healthcare & IVR transactions: lacks SSML /, custom lexicons, and 99.9% SLA; route to Azure AI Speech.
  • Real-time 3D avatar lip-sync & frame-locked dubbing: N x 160 ms patch quantization and zero visemes require Azure Speech (0.1 ms Viseme) or IndexTTS-2.
  • Sub-90 ms telephony barge-in loops: 160 ms patch floor (~135 ms TTFA) trails Cartesia Sonic 3.6 (~55 ms) and ElevenLabs Flash (~75 ms).
  • Ungated public voice cloning endpoints: zero built-in consent check or watermark; mandate live consent phrases + AudioSeal + FIDO2 anti-spoofing.

② 🎯 业务方与架构师灵魂拷问 Q&A（Q1 / Q2 / Q3）

Q1：Sora 2、Veo 3、Runway Gen-4、Kling 2.1 与自托管 Wan 2.2 各自的核心长板与适用边界是什么？

  • OpenAI Sora 2 Pro（$0.180/s · 150 RPM）：强项在于长时序复杂物理因果（流体飞溅、刚体碰撞）与大范围三维运镜连续性，适合品牌发布会 Hero TVC 主视觉；但单秒成本最高且不支持挂载企业私有 .safetensors LoRA 权重。
  • Google Veo 3 on Vertex AI（$0.140/s · 300 RPM）：强项在于原生双流音画联合生成（环境拟音、脚步声、角色口型对白同出）+ Google Cloud 企业级知识产权侵权赔偿（IP Indemnity）+ SynthID 隐形水印，是跨国企业有声社交广告首选。
  • Runway Gen-4 Turbo（$0.050/s · 500 RPM）：强项在于导演级相机运动画笔（Motion Brush）、单图角色一致性引用（Character Reference）与影视工业 NLE 插件生态，适合广告分镜预演（Previs）。
  • Kling 2.1 Master 可灵（$0.028/s · 900 RPM）：强项在于首尾帧精确锚定（First/Last Frame Lock）、电商模特肢体自然度与极高性价比，适合电商商品展示与换背景短视频规模化生成。
  • 阿里 Wan 2.2-14B FP8 on AKS / ComfyUI 自托管（$0.009/s · 3,200+ RPM）：强项在于数据 100% 不出私有 VPC、支持挂载内部专有角色/包装 LoRA 与 ControlNet Depth/Canny 像素级锁死，且单秒边际成本仅 $0.009，适合日产数万支的大促批量合成与保密游戏资产生产。

Q2：为什么企业 AIGC 视频中台必须设计“商业 API + AKS 自托管温池”双轨令牌桶溢出架构？

  1. 破解公有云 API 并发配额（RPM）天花板：哪怕预算充足，单一商业视频 API 的企业账号通常也有 150 ~ 500 RPM 并发限制。当大促零点涌入 2,400 RPM 的商品短视频生成请求时，纯 API 架构会出现 44.6% 的 HTTP 429 报错。
  2. 令牌桶水位线（80% Watermark）无感削峰：网关实时追踪各商业 API 的剩余令牌桶配额；一旦排队深度超过 8s 或配额消耗达 80%，自动将标准化图文转视频（I2V）任务分流至 Azure AKS / AWS EKS 上的 Wan 2.2 FP8 预热温池，实现 0.0% 限流丢包 与 $0.024/秒 的极致综合成本。

Q3：如何防止业务团队误将未公开新游设定图发往外部 API，或误用非商用开源权重投流广告？

  • 数据密级与版权条款双向门禁（Dual Policy Gate）：请求进入网关时，策略引擎校验 asset_confidentiality 与 campaign_tier：凡标记为 CONFIDENTIAL_PRELAUNCH_IP 的资产强制锁死在私有 VPC Wan 2.2 节点；凡标记为 FORTUNE500_EXTERNAL_AD 的资产强制路由至具备完整商业赔偿承诺且签发 C2PA v2.1 凭证的管线。

# Launch：外部视角的原创火箭

本演示在敦煌与 Astra 首轮上线、实际浏览器验证后开始制作。
白色火箭、发射台、格构塔、支架、罐体、管道、围栏与远山由原创几何生成，
不加载外部模型或纹理。大型圆框是观景边框，不是舱内相机。

## 几何与配色

分段圆柱壳体、锥形头部、环带、尾翼与喷口是真实三维几何。
红 #F25022、绿 #7FBA00、蓝 #00A4EF、黄 #FFB900 用作四条饰带与场地标线，
借鉴视觉配色但不自称官方品牌规范。没有 Microsoft Logo 或官方背书。

## 可复现的发射状态

待命 → 点火 → 建立推力 → 离台 → 升空 → 完成定格。
前四秒保持在台面，其后采用明确的时间高度函数，保证抬升单调。
这个函数只是艺术运动，不是根据推重比、质量消耗和大气求解的轨道仿真。
重复启动不生成多重发射，暂停保持场景和时间，重放清空烟雾并重新点火。

外部固定镜头保持位置不变，起飞时扩大视野并缓慢上仰，使地面与火箭均不被圆框裁掉；
跟随镜头平滑跟进火箭。
没有未经请求的随机镜头摇晃。减少动态效果设置关闭喷焰的高速波动，
不自动播放；主动 Launch 仍能观看完整发射。

## 喷焰与烟雾

喷焰是沿喷口向下的渐变透明几何与加色核心，不是流体模拟。
烟雾使用单次绘制的批量 Points，最多 640 个粒子、寿命回收；
按相机深度排序，关闭透明层深度写入。径向软遮罩形成近似云团。
排序和有限点片仍存在实时近似边界，不能称为真实体积烟雾或物理燃烧。

低帧率自动降低 DPR 和粒子发射率，状态显式披露。
失去 WebGL 上下文时保留进度并提示，恢复后重建渲染状态。
后台不推进运动；离开页面销毁 GPU 几何、材质和 renderer。

## 资料

- Three.js InstancedMesh / 批量原则
- Three.js Points
- 透明排序
- 材质深度与透明属性

使用批量 Points 而不是为每个烟团创建 Mesh，可降低 draw calls；选择 Points
是实现决策，不是声称必须用 InstancedMesh 才能批量渲染。

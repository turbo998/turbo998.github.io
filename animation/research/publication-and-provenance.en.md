# Publication & Provenance Boundaries

> 🌐 **Language / 语言**: [中文 (`publication-and-provenance.md`)](publication-and-provenance.md) | **English**

This repository contains original browser-native visual demonstrations and verifiable technical research:

1. **Astra Planet Lab (`demos/astra-planet/`)**: Uses official public-domain NASA PDS MGS MOLA (`MEG016`) laser altimetry data with SHA-256-verified derived packages (`mola-meg016-base-v1.bin` and `mola-meg016-hd-v1.bin`). All shaders, terrain/water Workers, GLB exporters, and Blender 4.5 Cycles micro-normal bakes (`mars-micro-normal.png`) are original MIT-licensed implementations.
2. **Winds Among the Murals · Feitian (`demos/feitian/`)**: Reference pages were studied solely for technical decomposition. Zero code, character illustrations, patterns, audio, or screenshots from reference sites are distributed. The four Feitian figures, PBD silk ribbons, WebAudio pentatonic synthesis, and Blender 4.5 Cycles orthogonal grotto relief bake (`grotto-relief-bake.png`) are original artistic tribute works and do not claim archaeological restoration.
3. **Launch · White Rocket (`demos/rocket-launch/`)**: Original Three.js launch complex and Blender 4.5 MCP hard-surface kit (`rocket-kit.glb`). Microsoft four-color accent stripes are a visual tribute with no official brand affiliation or endorsement.
4. **Zero Runtime Cloud / AI Dependencies**: Production builds (`dist/`) contain no API keys, model inference endpoints, Azure credentials, or external runtime CDNs. Third-party library licenses and NASA PDS citations are documented in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

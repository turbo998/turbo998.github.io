ORIGINAL / HASSELGREN CONSERVATIVE RASTIZATION DILATION RIG / NO NEURAL VOXEL COMPLETION EXECUTED

Dilate edge planes by Δd = h·(|n_x| + |n_y|). Stop sub-pixel wires & voxel walls dropping 70% of their pixels.

为什么在渲染远景高压电线、CAD 机械精细线框（亚像素半宽 `r = 0.20 px`），或者用 GPU 光栅化将薄墙壁三角形体素化进 3D 体素网格（VXGI 体素全局光照、碰撞检测体素场）时，如果直接使用传统的硬件像素中心点采样（Pixel-Center Point Sampling，只有图元覆盖了 `1×1` 像素格正中心的 `(x+0.5, y+0.5)` 才生成片元），斜向穿过的细电线就会断裂成一串支离破碎的虚线斑点，而薄体素墙壁上更是会漏出 **`12/17`（高达 `70.59%`）的穿透破洞**？因为当一条法线为 `n = (0.60, −0.80)`、半宽 `r = 0.20 px` 的斜线擦过像素正方形 `[−0.5, +0.5]²` 的左上角或右下角时，像素中心到斜线的垂直距离可达 `d = 0.50 px`（第 10 站）乃至 `0.80 px`（第 16 站）——明明斜线实实在在地切穿了这颗像素格的边角，像素中心点却落在斜线外面（`d > 0.20 px`），导致显卡直接丢弃该像素！而采用 Hasselgren 等人（GPU Gems 2, 2005）提出的闵可夫斯基和半像素保守光栅化扩张（Minkowski Conservative Dilation），将每条边沿其单位外法线 `n = (n_x, n_y)` 外推像素正方形的 $L_1$ 支撑半径 `Δd = h·(|n_x| + |n_y|) = 0.5·(0.60 + 0.80) = 0.7000 px`（总有效捕获阈值扩至 `R_cons = 0.20 + 0.70 = 0.9000 px`），即可 **100% 捕获全部 `17/17` 个被斜线碰触过的像素格（`0` 漏点、水密无破洞）**！An original 17-station 3D conservative rasterization bench compares Minkowski $L_1$ edge dilation against pixel-center sub-pixel dropout.

Conservative rasterization edge dilation is not neural voxel completion / 保守光栅化边扩张不等于神经体素补全推理

This bench evaluates deterministic Hasselgren, Akenine-Möller & Ohlsson (2005) Minkowski sum conservative rasterization (`R_cons = r + h*(|n_x| + |n_y|)`) versus naive pixel-center point sampling and 4-corner Separating Axis Theorem (SAT) interval testing across 17 pixel center distances (d ∈ [0.00, 0.80] px). It does not execute neural 3D occupancy completion networks.

在亚像素斜线半宽 `r = 0.20 px`、法线 `n = (0.60, −0.80)`、像素半宽 `h = 0.50 px`（闵可夫斯基支撑半径 `Δd = 0.7000 px`，真实边角相交上限 `R_cons = 0.9000 px`）跨越 17 个像素中心距离（`d = 0.00 .. 0.80 px`）时：Hasselgren 保守光栅化完整捕获全部 `17/17` 个相交像素（`0` 漏检）；而朴素像素中心点采样仅命中前 `5` 个中心距离 `d ≤ 0.20 px` 的像素，漏掉了后面整整 `12/17`（`70.59%`）个被斜线切穿边角的像素！

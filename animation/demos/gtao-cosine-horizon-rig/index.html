ORIGINAL / JIMÉNEZ GTAO COSINE-WEIGHTED HORIZON RIG / NO NEURAL AMBIENT OCCLUSION EXECUTED

Weight horizon visibility by Lambert's cos θ: V = ½(1 − cos 2γ) = sin² γ. Stop unweighted SSAO turning crevices muddy gray.

为什么在许多传统屏幕空间环境光遮蔽（SSAO / HBAO）实现中，建筑物街谷、墙角折痕与角色衣褶明明上方还留着 `2γ = 90°`（半张角 `γ = 45°`）的宽敞天空开口，算出来的环境光可见度却异常灰暗肮脏（Muddy Over-Darkening），总是跟离线路径追踪（Path-Traced Ground Truth）对不上？因为传统无权重立体角遮蔽（`V_unif = 1 − cos γ`）把所有方向的天空光线当成同等重要，忘了漫反射表面接收光能遵循**朗伯余弦定律 `cos θ`**！当一个凹槽底部头顶正上方 `θ ∈ [0°, 45°]` 敞开、而两侧掠射地平线 `θ ∈ [45°, 90°]` 被墙挡住时：头顶正上方的光线 `cos θ ≈ 1.0` 贡献了绝大部分照度，而被两侧墙壁挡住的掠射角光线 `cos θ → 0` 本来就没多少能量！如果忽略 `cos θ` 权重直接算立体角占比 `1 − cos 45° = 0.2929`，就会把真实余弦加权可见度 `sin² 45° = 0.5000` **错误压暗 `−0.2071`（相对压暗高达 `−41.42%`，在 `γ = 30°` 处更是相对压暗 `−46.41%`，污染全部 `17/17` 个孔径站点）**！Jorge Jiménez 等人（SIGGRAPH 2016，Activision / Unreal Engine 5 GTAO）严格将 `cos θ` 纳入地平线积分原函数 `V_GTAO(γ) = ½ cos n · (1 − cos 2γ) = cos n · sin² γ`，使屏幕空间 AO 第一次在数学上 100% 吻合离线路径追踪真值！An original 17-station 3D horizon heliodon bench compares Jiménez GTAO cosine-weighted horizon integration against naive unweighted solid-angle SSAO over-darkening.

Cosine-weighted GTAO horizon integration is not neural ambient occlusion / 余弦加权地平线积分不等于神经环境光遮蔽推理

This bench evaluates deterministic Jorge Jiménez et al. (SIGGRAPH 2016) Ground-Truth Ambient Occlusion (GTAO) cosine-weighted horizon integration (V_GTAO = ½ cos n · (1 − cos 2γ) = cos n · sin² γ) versus naive unweighted solid-angle SSAO (1 − cos γ) and 64-ring hemispherical quadrature across 17 sky-cone half-angle stations (γ ∈ [5°, 85°]). It does not execute neural ambient occlusion networks.

在开放天空半张角跨越 `γ = 5° .. 85°` 的 17 个孔径站点上（第 8 站 `γ = 45°` 对应直角墙角或街谷）：Jiménez GTAO 朗伯余弦加权积分因正确赋予头顶直射天空更高的 `cos θ` 权重，精确输出 `V_GTAO(45°) = sin² 45° = 0.5000`（全 17 站与 64 环半球路径追踪积分 `100%` 吻合，`0` 脏黑失真）；而朴素无权重立体角 SSAO 输出 `1 − cos 45° = 0.2929`（在第 8 站丢失 `−0.2071` 即 `−41.42%` 的可见度，把原本通透的墙角与衣褶染成脏黑煤灰，污染全部 `17/17` 站）！

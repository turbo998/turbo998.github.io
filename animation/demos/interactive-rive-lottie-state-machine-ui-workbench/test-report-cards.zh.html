MY TAKE · 选型边界

精确控制有用；逼真外观是另一项工作。

✅ 适合

  • Interactive AI Copilot mascots (idle -> listening -> thinking -> speaking -> interrupted) with continuous 2D cursor gaze and audio-amplitude lip-sync
  • 自动放行motive HMI digital instrument clusters, gamified mobile onboarding, and luxury brand interactive product cards requiring <50 KB bundle size at 60fps
  • Runtime theme color-slot binding and dynamic multilingual text runs inside vector skeletal rigs without re-exporting from After Effects

⛔ 不适合

  • Photorealistic live-action human spokesperson footage (use AI Avatar / WebM Alpha)
  • Simple 2-state CSS opacity/transform button hovers (use native CSS transitions)
  • Full-scene 360-degree CAD product inspection (use Three.js / R3F + 3DGS)

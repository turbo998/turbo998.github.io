MY TAKE · 选型边界

精确控制有用；逼真外观是另一项工作。

✅ 适合

  • Apple / Linear / Stripe style flagship product launch scrollytelling pages featuring 10 to 30+ interactive 3D/Shader chapters on a single page
  • Using a single fixed WebGL2 canvas with gl.scissor() and gl.viewport() virtualized into DOM placeholder bounding rects (Drei <View> / custom Scissor Orchestrator)
  • Combining IntersectionObserver 1-screen preload and ±2-screen LRU GPU texture disposal to prevent mobile iOS Safari memory jetsam crashes

⛔ 不适合

  • Spawning a new THREE.WebGLRenderer() and <canvas> for every scroll section (guaranteed to hit the 8/16 WebGL context limit)
  • Decoding 300 uncompressed 4K PNG sequence frames on the main UI thread during scroll events
  • Static plain-HTML documentation with zero 3D or canvas elements

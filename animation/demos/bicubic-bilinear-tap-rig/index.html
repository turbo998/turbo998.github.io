为什么许多游戏在开启时域抗锯齿（TAA）后，只要摄像机缓慢移动，地面石砖与角色衣服的锐利纹理就会在短短几帧内像涂了一层凡士林一样迅速变糊（Recursive History Blur Collapse）？因为每一帧 TAA 都要根据运动向量把上一帧的历史缓冲（History Buffer）在亚纹素位置（如中点 `u = 0.50`）重采样一次！如果直接用单抽头硬件双线性插值（`1-Tap Bilinear`）重采样一个曲率为 `κ = 0.16` 的高频纹理波峰（`T₀ = T₁ = 0.9600`，真实波峰中心 `C(0.5) = 1.0000`），单次双线性采样就会削平 `-4.00%` 的波峰，而在连续递归重采样 `K = 8` 帧后，波峰亮度会按 `0.96⁸ = 0.7214` 发生指数级坍塌（丢失 `−0.2786` 即 `27.86%` 的高频锐度，波及 `15/17` 个亚纹素站点）！可是标准的 `4×4` 双三次 Catmull-Rom 滤波需要 `16` 次独立纹理采样，对实时管线来说太贵了怎么办？Phillipp Sigg & Markus Hadwiger（GPU Gems 2, 2005）与 Jorge Jiménez（SIGGRAPH 2016）利用中心两项权重恒正（`w₁(u) > 0, w₂(u) > 0`）的代数性质，将两次点采样合并为偏移坐标 `s₁₂ = w₂ / (w₁ + w₂)` 处的**单次硬件双线性采样** `W₁₂ · lerp(T₀, T₁, s₁₂)`（在 2D 下将 16 次采样压缩为 5 次硬件双线性采样），在 `K = 8` 帧递归重采样后依然 100% 锁定 `C_hist = 1.0000` 满血锐度（`0` 模糊损失）！An original 17-station 3D history microdensitometer bench compares Sigg-Jiménez bilinear-merged bicubic resampling against naive 1-tap bilinear TAA blur collapse.

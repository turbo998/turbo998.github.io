Weight 2×2 HDR quads by w_k = 1/(1 + L_k). Stop 1-pixel specular glints exploding into bloom fireflies.

为什么在渲染带有阳光水面波光、汽车镀铬保险杠细窄倒角或金属边缘高光的实时 HDR 场景时，哪怕画面里只有 **1 个亚像素（Sub-Pixel）微表面闪光点** 冲到了 `L_0 = 512.0 nits`（而它周围同一个 `2×2` 纹素块里的另外 3 个像素都是正常的 `L_bg = 0.50 nits`），一旦直接用传统的线性均值降采样（`L_box = (L_0 + L_1 + L_2 + L_3) / 4`）生成第一级 Bloom 辉光金字塔，这 1 个亚像素噪点就会把整块 `2×2` 乃至 `8×8` 辉光贴图直接引爆到 `L_box = 128.3750`（产生 `128.63×` 的亮度过曝爆炸），并且随着镜头微移 0.5 个像素像迪斯科频闪灯一样在屏幕上疯狂忽明忽暗（Bloom Firefly Strobing）？因为算术平均对极端离群值没有任何抵抗力！而 Brian Karis (SIGGRAPH 2013) 逆亮度加权平均（Karis Average）在首级 `2×2` 降采样时为每个采样赋权 `w_k = 1 / (1 + L_k)`：由于单个极亮噪点的加权分子 `L_0 / (1 + L_0) < 1.0` 具有严格的渐近上界，即使亚像素高光飙升至 `512.0` 甚至 `32768.0`，Karis 降采样输出也稳稳收敛在 `L_Karis = 0.9981 ≤ 1.0000`（消除 `99.22%` 以上的萤火虫爆闪，全 17 站 `0` 过曝爆炸），同时在平坦光照区（`L_0 = L_bg = 0.50`）保持 `100%` 精确无损！An original 17-station 3D HDR bloom photometer bench compares Karis inverse-luminance weighting against linear box-filter firefly explosions.

Karis inverse-luminance HDR filtering is not neural Monte Carlo denoising / Karis 逆亮度加权不等于神经蒙特卡洛降噪推理

This bench evaluates deterministic Brian Karis (2013) inverse-luminance weighted 2×2 HDR downsampling versus naive linear box averaging and two-pass weight normalization across 17 sub-pixel glint intensities (L_0 = 0.5 × 2^i ∈ [0.5, 32768.0]). It does not execute neural path-tracing denoisers.

在 3 个背景相邻纹素均为 `L_bg = 0.50`、1 个亚像素高光纹素冲至第 10 站 `L_0 = 512.0` 的 `2×2` HDR 降采样块上：Karis 逆亮度加权（`w_k = 1/(1+L_k)`）输出 `L_Karis = 1025/1027 = 0.9981 ≤ 1.0000`（全 17 站 `0/17` 萤火虫爆闪）；而朴素线性均值滤波（`1/4 Σ L_k`）直接冲至 `L_box = 128.3750`（产生 `128.63×` 的过曝爆炸，在第 16 站 `L_0 = 32768.0` 时高达 `8192.5×`，引爆 `14/17` 个测试站）！

Change the scene.

Edit a track, not the screenshot.

All tracks must have unique IDs, increasing times and endpoints. Invalid JSON is rejected without replacing the last valid scene.

Keep intent separate from tool execution.

声明式场景记录“每条轨道在何时到哪里”；操作日志只记录“曾调用哪个按钮”。代码可以验前者，但不自动证明第三方 MCP 软件已执行。

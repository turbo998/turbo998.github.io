ORIGINAL / LAGARDE FROSTBITE SPECULAR OCCLUSION RIG / NO NEURAL AMBIENT OCCLUSION EXECUTED

Couple N·V, AO, and roughness via SO = (N·V + AO)^p − 1 + AO. Stop dark crevices glowing with sky reflections.

为什么在许多 PBR 基于图像照明（IBL）管线中，明明已经给环境漫反射乘上了烘焙 AO 或 SSAO（比如在角色鼻孔、腋下、汽车轮拱或机甲装甲深缝内部，`AO = 0.25`），但那些照不到阳光的阴暗深缝里却依然泛着一层诡异的“放射性蓝天高光（Cavity Specular Leak）”？因为许多初级着色器认为“AO 只代表漫反射遮蔽，不能直接乘在镜面反射上”，于是干脆对环境镜面反射完全不做遮蔽（`SO = 1.0000`）！结果在深缝掠射角（第 0 站 `N·V = 0.05`）处，微表面菲涅尔反射把头顶的亮蓝天空 100% 反射进深邃的暗缝里！反过来，如果粗暴地直接令 `SO = AO`，又会把光滑镜面在正视角（`N·V → 1`）下本没有被挡住的清晰倒影错误压暗！而 Sébastien Lagarde & Charles de Rousiers（SIGGRAPH 2014 Frostbite PBR，现为 UE5 与 Unity HDRP 标准）提出的视角-粗糙度耦合高光遮蔽公式 `SO = clamp((N·V + AO)^exp2(−16r − 1) − 1 + AO, 0, 1)`，在掠射角（第 0 站 `N·V = 0.05`，`AO = 0.25`，`r = 0.25`）处将高光遮蔽收紧至 `SO = 0.2131`（比 `AO = 0.25` 更严格地压住地平线漏光，消除朴素未遮蔽 IBL 高达 `+0.7869` 即 `4.69×` 的深腔反光泄漏），同时在光滑正视角下自适应放开高光能量！An original 17-station 3D cavity reflectometer bench compares Lagarde Frostbite specular occlusion against naive unoccluded IBL cavity leaks.

View-roughness specular occlusion is not neural ambient occlusion / 视角粗糙度高光遮蔽不等于神经环境光遮蔽推理

This bench evaluates deterministic Sébastien Lagarde & Charles de Rousiers (SIGGRAPH 2014 Frostbite) view- and roughness-dependent Specular Occlusion (SO = clamp((N·V + AO)^exp2(−16r − 1) − 1 + AO, 0, 1)) versus naive unoccluded IBL specular (SO = 1.0) and 64-step visibility-cone power quadrature across 17 viewing cosine stations (N·V ∈ [0.05, 0.85]). It does not execute neural screen-space ambient occlusion networks.

在深腔环境遮蔽 `AO = 0.25`、粗糙度 `r = 0.25`（指数 `p = 2^(−5) = 0.03125`）的第 0 站掠射角（`N·V = 0.05`）处：Lagarde 高光遮蔽因反射锥压向被遮挡的腔壁地平线，将高光遮蔽收紧至 `SO = 0.2131`（随视角升高至 `N·V = 0.85` 平滑过渡至 `0.2530`，全 17 站 `0` 深腔漏光）；而朴素未遮蔽 IBL 高光恒定输出 `1.0000`（在第 0 站产生高达 `+0.7869` 即 `4.69×` 的放射性深腔反光泄漏，污染全部 `17/17` 个视角站）！

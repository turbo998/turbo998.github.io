      对比维度
      🟦 FAF v2 (`customer-success-microsoft/faf-agents`)
      🟧 AGENT-FORGE (`microsoft/agent-forge`)
      🟩 HVE-Core (`microsoft/hve-core`)
    

  
  
    

      核心定位与哲学
      企业客户交付全生命周期（SDLC）专家团队：从业务优先级评分、加速器匹配到 Azure Landing Zone 与代码交付。
      仓库级 `.github/` 上下文工程元生成器 CLI：分析任意代码库并自动编译生成专属的多智能体团队与校验钩子。
      高流速工程（Hypervelocity Engineering）约定驱动工作流：通过严格分阶段的 RPI + `.copilot-tracking/` 文件契约消除复杂任务幻觉。
    

    

      核验版本与资产规模
      v2.0.1 (@a740ad88) · 590 git blobs · 3 插件包 · 15 Agents · 17 Skills · 6 企业级加速器目录
      v0.3.0 (@655ff340) · 38 git blobs · 11 内置元 Pipeline Agents · 6 个 CLI 命令 (forge 初始化/generate/validate)
      v3.3.101 (@c5de2020) · 2,753 git blobs · 14 领域集合 · 75 Agents · 75 Prompts · 76 Instructions · 49 Skills (共 275 项)
    

    

      Stage 1：立项与调研产出
      scorecard.yaml + prioritization-report.html（28 项整数评分 + 9 项门禁，算出 P1 Go: 78.0/90.9/87.5）
      scanner.ts 扫描 14 类技术栈清单，由 forge-greenfield-planner 生成架构需求画像
      task-researcher 派生并行 研究子智能体，产出 .copilot-tracking/research/2026-10-24/pelican-tour-pro-research.md
    

    

      Stage 2：规划与架构产出
      prd.md + spec.md（C4 L1–L3 架构 + 双连杆余弦定理 IK 方程）+ impl-rec.md（加速器打分 15% < 40% 走 路径 B）
      .github/forge-plan.json（定义 4 个专业 Agent 的 pipeline 串行 Handoff 拓扑与共享规则）
      task-planner + 计划验证器 产出双文件：pelican-tour-pro-plan.instructions.md + pelican-tour-pro-details.md + MADR v4.0 ADR-001
    

    

      Stage 3：防上下文污染机制
      按 SDLC 阶段隔离目录（scope/ → specs/ → plan/ → infra/），每个角色 Agent 只读写对应阶段文档
      为每个生成的子 Agent 设置最小化工具白名单（如 QA Agent 仅只读 read/search）与职责边界
      强制 /clear 上下文清空铁律：阶段间零聊天历史继承，100% 依靠 .copilot-tracking/ 日期前缀文件传递真理，彻底杜绝长对话漂移
    

    

      Stage 4：确定性校验与对抗审查
      compute_scores.py（强制 1–5 整数与 S1 证据溯源）+ faf_benchmark.py（53 项单元测试，零额外 LLM 调用统计 Token）
      forge validate（44 个 VS Code 工具名白名单 + Levenshtein <=3 自动纠错 + SKILL.md 触发词校验，实测 8/8 Passed）
      PowerShell/Pester + Vally 评测矩阵（Validate-SkillStructure.ps1 49/49 通过）+ task-challenger 纯冷态 What/Why/How 对抗式拷问
    

    

      Stage 5：鹈鹕骑自行车 Demo 风格
      🟦 工程动力学与骨骼透视工作台：专注精确踩踏几何、X-Ray 骨骼向量与膝角实时标注、变速齿比与功率遥测
      🟧 多智能体海滨互动艺术剧场：专注三幕光影氛围（晴空/落日/星夜车灯）、点击抛沙丁鱼接鱼吞咽、翘前轮特技与 WebAudio 铜车铃
      🟩 环法级多地形风洞专业仿真台 (Pelican Tour Pro)：专注 -10%~+15% 坡度重力/滚阻/风阻耦合、实时风洞烟雾流线、三种骑行姿态 (CdA) 与 11 速 Di2 电变
    

    

      最佳适用场景
      面向客户交付的 Azure GenAI / Microsoft Fabric 解决方案评估、架构规范编写与 Landing Zone 部署
      新项目冷启动或存量老项目一键生成符合团队栈特性的 .github/ Copilot 定制资产包
      跨多文件、高复杂度软件工程研发，需要强可追溯性（.copilot-tracking/）、安全/RAI/A11y 合规规划与对抗式代码审查

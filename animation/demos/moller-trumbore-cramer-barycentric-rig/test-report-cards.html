MY TAKE

Exact controls are useful; realism remains a separate job.

✅ Good fit

  • Hardware/compute BVH ray-triangle intersection kernels, embree/DXR/Vulkan Ray Query shaders, and mouse-picking raycasters (Moller & Trumbore JGT 1997)
  • Deformable skinned meshes and cloth simulations where precomputing and updating per-triangle plane equations N·P = d every frame wastes memory bandwidth
  • Arbitrarily oriented 3D walls, ceilings, and overhang geometry where fixed 2D plane projections degenerate
  • 2-cross-product Cramer solver replacing 64-step iterative matrix refinement

⛔ Not for

  • Purely 2D UI canvas hit-testing where all triangles lie strictly in the z = 0 screen plane
  • Sphere-only analytical raymarching
  • 1D audio buffer scrubbing
  • Axis-aligned 2D bitmap blitting

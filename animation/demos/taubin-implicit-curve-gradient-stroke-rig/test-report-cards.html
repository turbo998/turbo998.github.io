MY TAKE

Exact controls are useful; realism remains a separate job.

✅ Good fit

  • Implicit algebraic curve rasterization, topographic isolines, and Loop-Blinn GPU quadratic/cubic spline strokes (Taubin ACM TOG 1994)
  • Scientific function plotting f(x,y) = 0 where constant-pixel stroke thickness is required across varying gradient slopes
  • Procedural metaball and superellipse contour outlines
  • 1-divide gradient normalization replacing 64-step closest-point foot-of-normal root finding

⛔ Not for

  • Exact signed distance primitives that already satisfy the Eikonal equation ||grad d|| === 1 everywhere
  • Unstroked solid flat-color fills
  • 1D audio level meters
  • Pre-baked static bitmap icons

ORIGINAL / ANALYTIC RAY-DIFFERENTIAL FOOTPRINT RIG / NO NEURAL TEXTURE UPSCALING EXECUTED

Differentiate continuous U(x) before fract(U) or pass textureGrad(dU/dx). Stop 2×2 quad dFdx mip seams.

为什么在片元着色器里写下一行看似无害的周期平铺纹理采样 `texture(tex, fract(uv))` 或球面经度映射 `atan(z, x) / (2π)`，渲染出来的地板砖缝、圆柱贴图经线接缝或纹理图集（Texture Atlas）边界上，总是会莫名其妙地出现一条 **2 个像素宽的模糊黑线或低分辨率色带（Mipmap Seam Artifact）**？因为现代 GPU 光栅化器总是以 `2×2` 像素小方块（Pixel Quad）为单位并行跑片元着色器，并直接用相邻两个像素的寄存器差值 `dFdx(u) = u(2q+1) − u(2q)` 来估算纹理缩放率并选择 Mipmap 层级！当连续纹理坐标从第 8 号像素的 `U(8) = 0.9375` 平滑跨过整数边界来到第 9 号像素的 `U(9) = 1.0625` 时，一旦你先算了 `fract(U)`，两个像素里的数值就变成了 `0.9375` 和 `0.0625`。此时硬件 `dFdx(fract(U))` 算出的差值不再是真实的 `+0.1250 uv/px`，而是灾难性的 `|0.0625 − 0.9375| = 0.8750 uv/px`（**足迹暴增 `7.00×`**），导致这整个 `2×2` 像素块瞬间跳变到 **`+log₂(7.00) = +2.8074` 级更粗糙的模糊 Mipmap**，在画面上留下一道刺眼的 2 像素宽接缝！而采用解析展开射线微分足迹（在 `fract(U)` 之前对连续坐标求导并显式传入 `textureGrad(tex, fract(U), dFdx(U), dFdy(U))`），可在全 17 个像素站上严格锁死 `|∂U/∂x| = 0.1250 uv/px` 与 `LOD = 0.0000`（`0/17` 像素发生接缝跳变）！An original 17-station 3D screen-space quad differential bench compares analytic unwrapped ray differentials against GPU `2×2` quad `dFdx(fract(U))` mip-seam spikes.

Analytic ray-differential footprint evaluation is not neural texture upscaling / 解析射线微分足迹不等于神经纹理超分推理

This bench evaluates deterministic analytic unwrapped ray-differential footprints (`textureGrad` before `fract` wrapping) versus hardware GPU 2×2 pixel-quad finite differencing `dFdx(fract(U))` and 4-ray supersampled finite differences across 17 screen-space pixels. It does not execute neural texture super-resolution networks.

在连续 UV 斜率 `∂U/∂x = 0.1250 uv/px`（每块瓷砖 8 纹素，真实 Mip 层级 `LOD = 0.0000`）跨越第 0 号（像素 `0,1`）与第 4 号（像素 `8,9`）`2×2` 像素块的周期边界（`0.9375 → 0.0625`）时：解析展开射线微分在全 17 个像素站上恒定输出 `|∂U/∂x| = 0.1250` 与 `LOD = 0.0000`（`0` 接缝伪影）；而朴素硬件 `dFdx(fract(U))` 将跨界差值误判为 `0.8750 uv/px`（`7.00×` 足迹爆炸），在 `5/17` 个边界像素上产生 `+2.8074` 级 Mipmap 模糊跳变！

为什么在渲染多层交错的汽车车窗玻璃、CAD 机械剖面半透明外壳、粒子烟雾或能量护盾时，如果使用传统的 Porter-Duff `OVER` 混合公式 `C_out = α_src·C_src + (1 − α_src)·C_dst` 而不对每个三角形做逐帧深度排序，一旦镜头旋转或实例化批次先提交了近景亮玻璃（`z_near = 1.00 m, C = 0.90, α = 0.75`）、后提交了远景暗玻璃（`z_far = 3.25 m, C = 0.15, α = 0.75`），远景暗层就会“反客为主”盖在近景亮层上面，导致合成亮度从正确的 `0.7031` 瞬间暴跌至 `0.2813`（发生 `-60.00%` 的前后顺序倒置跳变）？因为 `OVER` 算子不可交换（`A over B ≠ B over A`），且交叉穿插的网格根本不存在全局正确的三角形排序！而 McGuire-Bavoil 加权混合顺序无关半透明（Weighted Blended OIT, WBOIT）将半透明合成分解为两个严格满足交换律的硬件混合通道：通道一执行深度加权加法累加 `Σ(α_k·C_k·w(z_k), α_k·w(z_k))`，通道二执行透射率乘法累乘 `Π(1 − α_k)`，无需任何 CPU/GPU 排序即可在任意提交顺序下给出比特级完全一致的平滑半透明！An original 17-station 3D OIT spectrophotometer bench compares commutative WBOIT against unsorted `OVER` depth inversion.

Commutative WBOIT accumulation is not neural layer decomposition / 可交换深度加权半透明不等于神经图层分解推理

This bench evaluates deterministic McGuire & Bavoil (2013) Weighted Blended Order-Independent Transparency (WBOIT) commutative depth-weighted accumulation versus unsorted Porter-Duff `OVER` blending and per-pixel A-Buffer sorting across 17 layer depth separations. It does not execute neural multi-layer alpha decomposition models.

在近景亮层（z_near = 1.00 m, C = 0.90, α = 0.75）与远景暗层（第 8 站 z_far = 3.25 m, C = 0.15, α = 0.75，正确后前排序合成值 C_sorted = 0.7031）发生绘制顺序调换时：WBOIT 可交换深度加权累加在正序与逆序提交下均输出完全一致的 C_WBOIT = 0.8375（前后提交顺序差 0.0000）；而朴素未排序 OVER 混合因远景覆盖近景直接跌至 C_unsorted = 0.2813（产生 −0.4219 / −60.00% 的前后翻转跳变误差）！

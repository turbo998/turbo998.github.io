MY TAKE

Exact controls are useful; realism remains a separate job.

✅ Good fit

  • Multi-cascade FFT ocean wave synthesis (Tessendorf Phillips/JONSWAP cascades) preserving target significant wave height H_s
  • Multi-octave fBm / Perlin / Gabor procedural noise normalized by 1 / sqrt(sum(w_k^2)) instead of 1 / sum(w_k)
  • Turbulent wind-field and procedural camera shake layering with invariant RMS energy
  • Single-inversesqrt L2 amplitude normalization inversesqrt(1.0 + sum_detail_variance)

⛔ Not for

  • Coherent in-phase copies of the exact same frequency mode k1 === k2 where cross-correlation is 1.0
  • Static 2D UI layout
  • Unanimated static meshes
  • 1D constant DC offset sliders

ORIGINAL / CHAN DIRECT-LIGHT CONTACT MICRO-SHADOWING RIG / NO NEURAL TEXTURE RELIGHTING EXECUTED

Gate direct sunlight by V_micro = clamp((N·L + 2·AO² − 1 + w) / 2w, 0, 1). Stop low sun leaking inside skin pores.

为什么即便给角色皮肤、粗麻布料和鹅卵石路面贴了 4K 法线贴图与精细的烘焙 AO 贴图（比如毛孔或缝隙底部 `AO = 0.50`），而且开启了 4K 级联阴影贴图（CSM），一旦走到斜射的阳光下，那些本该背光幽暗的毛孔、布料凹坑和装甲铆钉缝隙内部却依然被太阳直射光照得亮堂堂、像一块平坦的塑料皮（Direct-Light Pore Leak）？因为阴影贴图的单个纹素在世界空间有几厘米宽，根本无法为几毫米宽的法线贴图凹凸投射自阴影；而传统着色器又只把 `AO` 乘在环境光（IBL）上，对太阳直射光 `N·L` 完全不做遮挡！当斜射阳光的角度低于毛孔边缘倾角（如第 5 站 `N·L = 0.30 ≤ μ_cutoff − w = 0.30`）时，毛孔壁在物理上早已把阳光 100% 挡死，但未遮蔽的直接光照却让阳光直接穿透毛孔壁照亮孔底（泄漏 `E_sun = 0.3000` 直射光，波及 `13/17` 个斜射站点）！而 Danny Chan（SIGGRAPH 2018《Call of Duty: WWII》，现为 Unreal Engine 5 与 Frostbite 标准）提出的微阴影孔径门控公式 `V_Chan = clamp((N·L + 2·AO² − 1 + w) / 2w, 0, 1)`，直接从现成的标量 `AO` 反推出凹坑可见锥阈值 `μ_cutoff = 1 − 2·AO² = 0.50`，在斜射阳光下为每一个法线贴图毛孔免费生成锐利的毫米级自阴影！An original 17-station 3D pore goniometer bench compares Chan AO-derived direct-light micro-shadowing against naive unshadowed `N·L` pore leaks.

AO-derived contact micro-shadowing is not neural texture relighting / 孔径微阴影门控不等于神经纹理重打光推理

This bench evaluates deterministic Danny Chan (SIGGRAPH 2018 Call of Duty: WWII) AO-derived direct-light contact micro-shadowing (V_Chan = clamp((N·L + 2·AO² − 1 + w) / (2w), 0, 1)) versus naive unshadowed direct lighting (E = N·L) and 64-strip solar-penumbra aperture quadrature across 17 solar cosine stations (N·L ∈ [0.05, 0.85]). It does not execute neural intrinsic texture relighting networks.

在毛孔或织物凹坑烘焙遮蔽 `AO = 0.50`（孔径截断余弦 `μ_cutoff = 1 − 2·AO² = 0.5000`）、半影半宽 `w = 0.20` 的第 5 站低角度斜射阳光（`N·L = 0.30`）处：Chan 微阴影门控因阳光低于毛孔边缘倾角将直接可见度严格锁死为 `V_Chan = 0.0000` 与 `E_sun = 0.0000`（并在 `N·L ∈ [0.30, 0.70]` 平滑展开半影，全 17 站 `0` 穿壁漏光）；而朴素无微阴影直接光照在第 5 站漏出 `E_sun = 0.3000`（在 `N·L = 0.05 .. 0.65` 的 `13/17` 个斜射站点让太阳直射光穿透毛孔壁，使粗糙细节表面失去立体颗粒感）！

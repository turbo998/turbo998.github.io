Pre-integrate IBL BRDF as F₀·scale(N·V, r) + bias(N·V, r). Stop rough clay glowing like a mirror at grazing angles.

为什么在用环境光贴图（Image-Based Lighting, IBL）照亮一块粗糙的哑光橡胶轮胎、水泥墙或陶土雕塑（基础反射率 `F_0 = 0.04`，粗糙度 `r = 0.85`）时，如果直接把模糊后的环境光乘上宏观法线与视线夹角的 Schlick 菲涅尔公式 `F(N·V, F_0) = F_0 + (1 − F_0)(1 − N·V)⁵`，物体轮廓边缘（第 0 站掠射角 `N·V = 0.05`）就会冒出一圈像涂了水银或放射性荧光一样刺眼的纯白镜面亮边（反射率飙升至 `0.7828`，比真实微表面积分值暴增 **`24.48×`**）？因为菲涅尔反射定律作用在**微观斜面半程向量 `V·H`** 上，而非宏观平均法线 `N·V` 上！当表面非常粗糙（`r = 0.85`）时，一方面朝向相机的可见微表面半程角分布被大幅展宽（五次方均值降为 `(1 − (1−r)⁶)/(6r) = 0.1961`），另一方面背向倾转的微表面被 Smith 几何遮蔽函数 `G_2` 强烈拦截！而 Brian Karis (SIGGRAPH 2013) 提出的分离求和近似（Split-Sum Approximation）将环境 BRDF 对半程角的积分拆解为与 `F_0` 线性无关的两个预积分通道 `R_IBL = F_0 · scale(N·V, r) + bias(N·V, r)`，在 `N·V = 0.05` 掠射角处将粗糙陶土的环境反射率精准抑制在 `0.0320`（全 17 个观测角 `0` 放射性白边伪影）！An original 17-station 3D IBL reflectometer bench compares Karis Split-Sum DFG pre-integration against naive macroscopic Schlick Fresnel grazing halos.

Karis Split-Sum IBL DFG pre-integration is not neural environment estimation / 分离求和环境 BRDF 不等于神经环境光估计推理

This bench evaluates deterministic Brian Karis (SIGGRAPH 2013) Split-Sum IBL Environment BRDF scale-and-bias pre-integration (`F_0 * scale + bias`) versus naive macroscopic Schlick Fresnel `F(N·V, F_0)` and 192-point composite Gauss-Legendre quadrature across 17 view cosines (N·V ∈ [0.05, 0.93]). It does not execute neural illumination estimation networks.

在非金属基础反射率 `F_0 = 0.04`、粗糙度 `r = 0.85` 的第 0 站掠射边缘（`N·V = 0.05`）处：Karis 分离求和环境 BRDF（`scale = 0.1461, bias = 0.0261`）将环境镜面反射率精准控制在 `R_IBL = 0.0320`（全 17 站 `0/17` 掠射白边过曝）；而朴素宏观 Schlick 菲涅尔直接按 `1 − N·V = 0.95` 的五次方冲高至 `0.7828`（产生 `24.48×` 的放射性白边过曝，污染 `13/17` 个观测角站点）！

Filter premultiplied tuples (αC, α). Stop straight-alpha bilinear dark halo fringes.

为什么把一张边缘全透明（RGB=0, α=0）的亮色贴图、半透明烟雾粒子或视频抠像图层放在明亮背景（I_bg = 0.90）上做双线性采样缩放（Bilinear Filtering / Mipmapping）时，如果采用“直通非关联 Alpha（Straight Unassociated Alpha）”模式，明明前景亮度是 1.00、背景亮度是 0.90，交界处却会凭空冒出一圈刺眼的深灰黑边（Dark Halo Fringe，亮度暴跌至 0.7000）？因为直通 Alpha 先把前景 RGB 与透明像素里的 (0,0,0) 线性混合得 (1−t)C_fg，合成时又再乘了一次 α=(1−t)，导致前景权重被错误平方成了 (1−t)²！而预乘关联 Alpha（Premultiplied Associated Alpha）存储并插值 C̃ = αC，与双线性插值及 Mipmap 严格满足交换律。An original 17-tap 3D optical silhouette photometer bench compares premultiplied associated alpha filtering against straight alpha dark-fringe bleeding.

Associative Porter-Duff alpha filtering is not neural video matting / 预乘关联 Alpha 光学合成不等于神经视频抠像推理

This bench evaluates deterministic Porter-Duff OVER compositing under bilinear texture filtering: Premultiplied Associated Alpha (C̃ = αC) versus Straight Unassociated Alpha across a 17-tap silhouette boundary. It does not execute RVM, MatAnyone, or neural alpha matting diffusion networks.

在前景辐射度 C_fg = 1.00、明亮天空背景 B_sky = 0.90 的第 8 号双线性插值中点（t = 0.50, α = 0.50）处：预乘关联 Alpha 输出单调平滑的精确中点辐射度 I_out = 0.9500（黑边凹陷 0.0000，光能损失 0.00%）；而直通 Alpha 因透明像素 (0,0,0,0) 颜色渗漏与 α 二次相乘，将中点辐射度拉低至 0.7000（比 0.90 的天空背景还暗 0.2000，相对真实值凹陷 −0.2500、损失 26.32% 边缘光能），形成明显的深灰黑边脏环！

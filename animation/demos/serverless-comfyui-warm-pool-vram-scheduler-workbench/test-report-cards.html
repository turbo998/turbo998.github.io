MY TAKE

Exact controls are useful; realism remains a separate job.

✅ Good fit

  • Enterprise self-hosted ComfyUI / Diffusers Kubernetes clusters serving 500+ designers or multi-tenant SaaS APIs on H100 / L40S / A100 GPUs
  • Consistent-hash DAG routing that pins 24GB/28GB base models (Flux.1, Wan 2.2, SDXL) in dedicated GPU pools while hot-swapping 150MB tenant LoRAs in <180ms
  • Pre-staging `.safetensors` checkpoints on local NVMe RAID-0 / `/dev/shm` with zero-copy `mmap` and CRIU/CUDA snapshots (<1.8s warm-up)

⛔ Not for

  • Stateless round-robin load balancers (Nginx least_conn) that ignore which 28GB checkpoint is currently resident in each worker VRAM
  • Pulling 24GB weights over slow network NFS/S3 on every container scale-up
  • CPU-only static HTML web hosting with no GPU model weights

MY TAKE · 选型边界

精确控制有用；逼真外观是另一项工作。

✅ 适合

  • Cloud & AI Solution Architects authoring CTO pitch decks, Azure/AWS/Fabric reference architectures, and executive decision infographics
  • Compiling LLM-generated JSON topology ASTs via ELK.js orthogonal routing into 100% editable native PowerPoint (.pptx), Draw.io (.drawio), and interactive SVG figures
  • Using AIGC strictly for text-free glassmorphism hero illustrations or subtle card backdrops while keeping all diagrams, icons, and KPI numbers 100% vector-native

⛔ 不适合

  • Asking image diffusion models (Midjourney / Flux / GPT-Image) to rasterize an entire technical architecture diagram or data table into a flat PNG
  • Delivering uneditable bitmap slides to enterprise customers who need to edit node labels in PowerPoint
  • Audio-only voice memos

MY TAKE

Exact controls are useful; realism remains a separate job.

✅ Good fit

  • Tornado funnels, aircraft wingtip contrails, smoke rings, and magical swirl particle systems
  • Regularizing singular Biot-Savart 1/r vortex filaments via r/(r^2 + r_c^2) so near-core particles orbit smoothly in solid-body rotation instead of slinging outward like shrapnel
  • Computing smooth tangential advection without square roots using squared distance r^2 = dx^2 + dz^2

⛔ Not for

  • Uniform rectilinear wind fields with zero vorticity curl (omega = 0)
  • Static architectural meshes with no particle or fluid advection
  • 1D UI progress bars

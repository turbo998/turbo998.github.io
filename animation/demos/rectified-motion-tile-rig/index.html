ORIGINAL / MCGUIRE NEIGHBORMAX MOTION-BLUR TILE RIG / NO NEURAL FRAME INTERPOLATION EXECUTED

Dilate tile velocity via NeighborMax(3×3) with soft depth gating. Stop motion blur getting scissor-clipped at silhouettes.

为什么在许多后处理运动模糊（Post-Process Motion Blur）实现中，当一把高速挥舞的亮色飞剑或飞驰的汽车（前景深度 `z_fg = 1.50 m`，速度 `v_fg = 16.0 px/frame`）掠过静止的暗色背景墙面（背景深度 `z_bg = 10.0 m`，速度 `v_bg = 0.0 px/frame`）时，物体**内部**虽然被模糊了，但物体的**外轮廓边缘（`d = 0 px`）却像被剪刀齐根剪断一样锋利生硬**，本该向外溢出 8 个像素（`d = +1 .. +8 px`）的半透明残影拖尾完全消失不见？因为在外轮廓外侧 1 个像素的第 5 号背景像素（`d = +1 px`）上，G-Buffer 速度缓冲里记录的是**静止背景墙自己的速度 `v_center = 0.0 px/frame`**！如果运动模糊着色器只沿着当前中心像素自己的速度 `v_center` 去采样，它在所有背景像素上算出的模糊半径都是 `0`，导致前景高速物体的外部残影被 `100%` 一刀切死（在第 5 站丢失 `−0.4375` 的拖尾亮度，波及全部 `7/17` 个外部拖尾像素）！而 Morgan McGuire 等人（I3D 2012）与 Jorge Jiménez（SIGGRAPH 2014）提出的 `TileMax + 3×3 NeighborMax` 速度分块扩张架构，先将前景最大速度 `v_NeighborMax = 16.0 px` 广播至相邻背景图块，再配合双边圆柱核与软深度前后遮挡门控，使运动拖尾在 `d = −8 .. +8 px` 全程呈现 `100%` 物理对称的快门积分斜坡！An original 17-station 3D shutter densitometer bench compares McGuire `NeighborMax` tile-dilated motion blur against naive center-velocity silhouette clipping.

McGuire NeighborMax motion-blur reconstruction is not neural frame interpolation / 分块最大速度运动模糊不等于神经光流插帧推理

This bench evaluates deterministic Morgan McGuire et al. (2012) & Jorge Jiménez (2014) NeighborMax tile-dilated motion-blur reconstruction with soft depth classification versus naive center-velocity gather and 64-tap brute-force neighborhood search across 17 silhouette boundary pixels (d ∈ [−4, +12] px). It does not execute neural optical-flow frame interpolation networks.

在前景运动速度 `v_fg = 16.0 px`（半快门模糊半径 `R = 8.0 px`，前景深度 `z_fg = 1.50 m`，静止背景深度 `z_bg = 10.0 m`）跨越物体轮廓边界（第 4 站 `d = 0 px`）来到外侧第 5 站背景像素（`d = +1 px`）时：McGuire `NeighborMax` 速度扩张（`v_NeighborMax = 16.0 px`）将半透明运动残影平滑溢出至背景，`C_out = 0.4375`（并在 `d = +1 .. +7 px` 的 7 个外部站点形成连续衰减斜坡，`0` 剪断伪影）；而朴素中心像素速度查表因读到背景 `v_center = 0.0 px` 直接在 `d = +1 px` 处断崖归零为 `0.0000`（丢失 `−0.4375` 拖尾亮度，一刀剪断全部 `7/17` 个外部残影站点）！

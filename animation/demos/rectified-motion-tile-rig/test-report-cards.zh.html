MY TAKE · 选型边界

精确控制有用；逼真外观是另一项工作。

✅ 适合

  • UE5、Unity HDRP、Call of Duty 与 DOOM 中的后处理物体与相机运动模糊（TileMax + 3×3 NeighborMax）
  • 直观解释为何在静止背景像素上按自身 v_center=0 模糊会把前景高速物体的外部残影 100% 一刀切死
  • 通过可分离 TileMax 与 3×3 NeighborMax 通道将主导最大速度扩张至相邻背景图块，再执行软深度双边采样
  • 以 O(1) NeighborMax 图块查表替代高开销的 64 点全邻域暴力速度搜索

⛔ 不适合

  • 相机与物体速度全为零（v = 0）的纯静态建筑展示场景
  • 需要极坐标角速度弧线模糊的超高速旋转螺旋桨扇叶
  • 神经光流视频补帧推理模型（RIFE / DLSS 3 帧生成）
  • 在镜头摇移时必须保持锐利清晰的 2D UI 文字层

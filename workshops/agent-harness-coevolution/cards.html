SCENARIO · THE 12KB ROUTER CLIFF 2 / 7

Root Cause: How 80 out of 81 User Skills Turned Invisible to the Semantic Router

The agent runtime caps <available_skills> injection at ~12 KB (12,000 chars); overflow entries silently lose their YAML description and degrade to bare names.

✕ Before: Multi-Paragraph Essay Frontmatter

description: >
  Use this comprehensive skill whenever the user
  asks to create, polish, restructure, or review
  executive slide decks, customer workshops...
  (Avg 476 chars/skill · accessibility = 1.1 KB)

✓ After: ≤140-Char Dense Routing Trigger

description: "Build Azure Fluent executive slide decks, architecture review presentations, and HTML/PPTX storyboards with dark/light contrast grids."
# Avg 129 chars across 62 skills = 8,019 chars
Failure Mechanism: With 22 project/plugin skills consuming ~4 KB first and user descriptions averaging 476 chars, ~16 verbose skills exhaust the entire 12 KB window. Truncation throws no error—skills simply stop triggering.

UNDER THE HOOD · PROGRESSIVE DISCLOSURE 4 / 7

Progressive Disclosure: Splitting a 1,390-Line Monolith into an 84-Line Router

Refactoring openclaw-wechat-deployment cut eager context injection from 54.7 KB to 3.4 KB (-94.0%) while preserving deep stage runbooks on demand.

What Stays in SKILL.md (≤120 Lines Cap)?

  • ≤140-char high-signal trigger contract (when / when not to invoke)
  • Hard architectural & security invariants
  • Stage routing table pointing to exact references/*.md files

What Moves to references/ & scripts/?

  • Full Bicep, cloud-init, Docker Compose & Nginx templates
  • Symptom-to-remediation troubleshooting matrices
  • Deterministic verification scripts & cross-OS helpers
Architectural Shift: Treat SKILL.md as an index router rather than a textbook. Frontier models natively call view on the exact reference file needed for the active deployment stage.

ROBUSTNESS · FRONTIER MULTI-MODEL MATRIX 5 / 7

De-Scaffolding Legacy Crutches & Aligning the Frontier Model Matrix

Eliminating obsolete model overrides, hallucinated tools, and OS-locked fonts to unlock multi-model specialization.

Three Legacy Crutches Removed

  • Hardcoded Obsolete Models: Stripped model: gpt-5.4 / gpt-4o-mini / claude-haiku-4.5 so subagents inherit runtime /subagents frontier routing.
  • Hallucinated Tool Names: Replaced fake search-the-web, fetch_page, and runSubagent with real web_search, web_fetch, task(...), and native Canvases.
  • macOS Font Lock-In: Fixed CJK tofu boxes on Windows/Linux in invoice_edit.py via fallback chain msyh.ttc → NotoSansCJK → PingFang.ttc.

MODEL-SKILL-MATRIX Specialization

  • Gemini 4 Carbon (long_context): Whole-repo synthesis, SVG diagrams (anatomy / architecture-diagrams), bilingual reports & PPT/Web artifacts.
  • GPT-6.2 Sol (high/xhigh/max): Complex Bicep/AKS IaC, OWASP/RAI security audits, strict RPI engineering & financial validation.
  • Grok 4.7 (high/xhigh): Live web signal intelligence (wechat-article / research), adversarial red-teaming & rapid incident triage.
  • Gemini 3.8 Flash: High-fanout read-only explore / task sweeps.

MY TAKE · PLAYBOOK FOR ENGINEERING TEAMS 7 / 7

Repeatable 5-Step Agent Harness Upgrade Playbook for Every Model Leap

An actionable engineering checklist to run whenever your organization registers a new frontier model cohort.

1 · Telemetry Audit First

Query session_store_sql tool_requests to expose zero-call zombie skills and cross-directory plugin duplicates using real invocation evidence.

2 · Enforce a < 9 KB Prompt Budget Guardrail

Cap user-level <available_skills> YAML metadata below 9 KB with ≤140-char trigger descriptions to leave 3–4 KB headroom under the 12 KB cliff.

3 · Refactor into Progressive Disclosure (≤120 Lines)

Keep SKILL.md ≤ 120 lines focused strictly on triggers, invariants, and stage routing; move Bicep, configs, and runbooks to lazy-loaded references/.

4 · Re-Bind Model Capabilities & OS Portability

Delete hardcoded legacy model pins and fake tools; align domains across Gemini 4 Carbon, GPT-6.2 Sol, Grok 4.7, and Gemini 3.8 Flash with cross-OS font/path fallbacks.

5 · Wire an Automated CI Regression Gate

Run automated checks on skill count, metadata byte budget, banned legacy tokens, and duplicate folder names on every skill sync or PR.

7 / 7 · MY TAKE

Production readiness is strong for governed runtimes, weak for key-in-container patterns.

✅ Good fit
  • Coding Agent sandbox: ACA Dynamic Sessions for managed fast isolation; E2B when deep runtime control needed
  • Browser/CUA cluster: ACA Sandboxes or E2B with explicit pause/resume and WebSocket routing
  • Multi-tenant SaaS Agent Gateway: APIM AI Gateway + AKSClaw hard boundaries + Entra Agent ID
  • Financial zero-trust execution: Kata/Firecracker isolation + private networking + deterministic policy audit
⛔ Not for
  • Coding Agent sandbox: Shared container without hard isolation or policy gateway
  • Browser/CUA cluster: Stateless request function without workspace persistence
  • Multi-tenant SaaS Agent Gateway: Direct key distribution into agent pods
  • Financial zero-trust execution: No attestation / no egress governance / opaque tool path

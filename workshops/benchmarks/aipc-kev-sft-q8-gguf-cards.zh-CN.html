Why Prompt Policy Injection (✕) and Long Uncompressed History (✕) fail on edge. B0-policy inflates prompt length from ~950 to ~4,600 chars, slowing laptop CPU inference 6.5x (666 -> 4,353 ms) while stalling at 60.8% accuracy. On 3k–8k token transcripts, accuracy drops to 44.9% (26.4s).

# 2. Run on AIPC CPU within 2.1–2.5 GiB RAM (987/987 bitwise-identical to -c 8192)
llama-server -m Contoso-Kev-0.8B-FTcf-R2C-Q8_0.gguf \
  -c 2048 -b 512 -ub 512 --cache-ram 0 -np 1
# Prefill forward pass extracts h_opt_i & h_decide -> <answer> probabilities in 386 ms
At <answer> Kev computes option probabilities in one prefill pass with zero autoregressive token decoding. Shrinking context flags from -c 8192 -b 2048 -ub 2048 to -c 2048 -b 512 -ub 512 cuts Windows commit memory from 5,014 MiB to 2,119 MiB (-2,895 MiB) with 987/987 identical predictions.

MY TAKE

Production-Ready for Structured AIPC Decisions (<2k Tokens, 2–3 GB RAM)

✅ Good fit
  • Offline or privacy-strict AI PC (Snapdragon X Elite / Intel Core Ultra / AMD Ryzen AI) structured routing, entitlement, and policy gating within 2.1–2.6 GiB CPU RAM
  • Multi-decision atomic forms (scoring 3–5 policy questions in a single 386–851 ms prefill pass) where prompt-stuffing is 6.8x slower and 35.5 pts less accurate
  • Uncertainty-gated workflows using T=2.83 calibrated probabilities (ECE 0.009–0.025) to auto-execute 90–100% of ID tickets at <=5% error
  • Fast enterprise policy updates: 4,038 counterfactual rows + 1,000 replay rows train in 22.7 min on 1x H100 (7.5 GiB VRAM)
⛔ Not for
  • Uncompressed multi-turn chat transcripts > 2,048 tokens (on 3k–8k token logs, accuracy falls to 44.9% and latency spikes to 26.4s)
  • Open-ended free-form text generation (Kev's pointer head scores discrete candidate options in a single prefill pass)
  • Single-instance high-concurrency CPU queuing (N >= 8 on 8-vCPU x64 queues linearly at ~0.93 req/s while inflating RAM to 3.8–6.9 GiB)
  • Naive 4-bit quantization or Adreno OpenCL GPU offload (-ngl 99 is 1.5x slower than CPU and adds 1.8 GiB working set + 3.4 GB shared RAM)

Delivered Artifact: Contoso-Kev-0.8B-FTcf-R2C-Q8_0.gguf (775 MiB, T=2.83) · 2.1–2.6 GiB CPU RAM · 96.3–100.0% ID Accuracy.

六层架构，一条端到端关键路径

更快的 GPU 无法修复堵塞的网络、错误的 KV 布局或过低的有效工作可用率。沿六层关键路径定位瓶颈，再用原始计算器一次改变一个假设。

  1. 判断限制来自计算、HBM 容量、带宽还是排队。
  2. 沿 NVLink、跨机网络与 KV 交接跟踪字节量和所有权。
  3. 只重叠相互独立的任务，并检查瞬时显存与正确性。
  4. 在固定质量与尾时延 SLO 下评估每个有效词元的成本。
证据边界：来源报告是 CPU 离线分析与仿真（synthetic），不是新的加速器实测。原始 own-offline 与 independently_reproduced=true 标签仅描述原报告的 CPU 验证。本次本地化不重跑上游实验。

L1 · 芯片与 HBM 屋顶线

P ≤ min(Ppeak, BHBM × I); I = FLOPs / bytes

当算术强度低于拐点 I = Ppeak/BHBM 时，内核受显存带宽限制；超过拐点后才可能受计算能力限制。在 SRAM 中复用分块可以提高算术强度；增大批量也可能有效，但会占用更多 KV 容量并增加排队时延。张量峰值算力不是应用吞吐量。

同时检查数据搬运量、寄存器压力与占用率；分块过大会造成寄存器溢出，抵消数据复用收益。

一手文档: CUDA Programming Guide

L2 · 机内与跨机互联

Tring ≈ 2(p−1)α + 2(p−1)S/(pB)

NVLink 提供机内扩展互联；NVLS 利用 NVLink Switch 的归约能力。SHARP 把支持的归约操作下沉到跨机网络。UEC 解决以太网传输与拥塞问题，不等于算术卸载。环形 AllReduce 对大张量能有效利用带宽，但启动时延项随参与进程数增长。

S 为张量字节数，p 为进程数，α 为每跳启动时延，B 为有效链路带宽。树形与卸载收益取决于数据类型、拓扑和争用，不能把查询表外推到任意网络。

一手文档: NCCL NVLS · SHARP · Ultra Ethernet Consortium

L3 · 分布式训练与优化

Tstep ≈ Tcompute + max(0, Tcomm − Toverlap)

FSDP2 对参数、梯度和优化器状态分片，在需要时全收集参数。预取用更多瞬时显存换取通信重叠。DualPipe 通过双向流水线调度隐藏通信与气泡。Muon 对矩阵更新做正交化；优化器开销与收敛行为必须单独验证，不能用流水线加速比替代。

一手文档: FSDP2 · DualPipe · Muon

L4 · KV 放置与注意力执行

MKV = 2 × L × T × Hkv × D × b; Txfer ≥ bytes/B

Mooncake 把 KV 存储和传输与计算解耦；NIXL 抽象不同数据搬运后端。FlashMLA 针对压缩潜在 KV 表示优化注意力执行。FP4 KV 减少字节数，但需要缩放元数据、兼容内核和质量验证。这里的标准多头 KV 公式不能直接套用于 MLA 潜在缓存。

L 为层数，T 为缓存词元数，Hkv 为 KV 头数，D 为头宽，b 为每元素字节数。假设各层尺寸相同，56 层 FP8 加 8 层 BF16 使用 72 而非 128 个字节单位，节省 43.75%。跳过 16 页中的 11 页可减少这类写入的 68.75%，不是减少全部推理流量。

一手文档: Mooncake · NIXL · FlashMLA

L5 · 投机解码与约束生成

Speedup ≈ E[accepted tokens + 1] × Ttarget / (Tdraft + Tverify)

EAGLE-3 生成候选词元，由目标模型校验。接受率高并不足够：草稿与校验的总开销必须小于省下的目标模型执行成本。XGrammar 屏蔽违反文法的词元。语法合法不代表事实正确或操作已获授权，文法处理开销也必须计入时延预算。

应在相同质量与尾时延 SLO 下比较端到端有效吞吐。更大的候选树可能增加接受词元，也可能浪费校验算力与 KV 显存。

一手文档: EAGLE-3 · XGrammar

L6 · 可靠性、可用性与成本

$/1M = ($/GPU-hour) × 10⁶ / (tok/s × ETTR × 0.85 × 3600)

只有检测、检查点与重启链路经过验证，NVRx 恢复机制和 RAS 遥测才能减少丢失的工作。成本核算应以有效交付量作分母，而不是峰值容量。计算器采用三年周期、每千瓦时 $0.065 电价和固定 0.85 推理利用率；这些是情景假设，不是厂商报价。

TCO = GPU 数量 × 单卡资本支出 + GPU 数量 × 单卡 IT 功率 × PUE × 26280 小时 × 电价。ETTR 折减有效计算与词元交付，不折减通电时长。模型未单独核算网络、人力与融资成本。

一手文档: NVRx

7 / 7 · MY TAKE GOOD FIT vs NOT FOR & READINESS

Enforce Deterministic Policy + Hardware Intent Quorum on Every High-Impact Agentic & Treasury Path

✅ Good fit (强烈推荐适用场景)

• 加密资产金库、跨链桥与清结算智能体：需要硬件 TEE 反编译校验 UI Summary == Raw Calldata 并在 <180ms 内阻断异常多池抽干。

• 企业级 MCP 工具网关与多智能体编排 (A2A)：防止恶意第三方 MCP 影子参数窃密与低权限子 Agent 混淆代理人提权。

• 处理外部不可信网页/文档的 RAG 与金融投研助手：通过 Spotlighting 彻底隔离间接提示词注入。

• 自动化红队渗透测试与 CI/CD 安全门禁：在上线前量化验证 Canary 零泄露与 0.0% ASR。

⛔ Not for (严禁误用场景)

• 仅靠 System Prompt 自然语言叮嘱来保护资金或生产密钥：在 Base64 混淆与多轮施压下失守率高达 87.5%。

• 允许 MPC 分片或硬件钱包对未解析的交易 Hash 进行盲签 (Blind Signing)：无法识别上层编排器被劫持后的载荷调包。

• 在共享宿主机内核且未封禁 169.254.169.254 的普通容器中运行不可信 Agent 代码。

• 使用分钟级人工审批告警替代毫秒级图异常自动熔断器。

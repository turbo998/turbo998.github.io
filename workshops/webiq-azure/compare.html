容易用错的默认值

  • Parallel mode 默认 advanced，是 $5/1k，不是 $1 的 fast。
  • Exa lite 不能现抓。现价要用能设 maxAgeHours=0 的类型。
  • Tavily 未付费计划设置 max_age_hours 可能返回 434。
  • Perplexity Search API：标准 $5/1k，fast $1/1k。一次请求最多 5 个 query 仍算 1 个计费单位。本仓库未调用。
  • Grounding with Google Search 和 Grounding with Bing 都是 $14/1k 的答案接地，不是 Web IQ，也不是原始结果页。Bing Search API 已于 2025-08-11 停用。
  • Brave 定价仪表盘本次渲染为空壳。研究提取写的是 $5/1k，本页不把它画成已复核标价。
  • Stage 1754 新增：Web IQ 支持 x-apikey 与 Entra ID Bearer（scope https://api.microsoft.ai/.default）双鉴权；缺两者返 401 AuthKeyMissing，Entra 缺 appid 返 400 InvalidRequest，AppID 未注册返 403 AuthUnauthorized；官方 SDK pip install webiq 与 npm install @microsoft/webiq 已上线。

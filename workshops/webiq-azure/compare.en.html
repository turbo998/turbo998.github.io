Defaults that bill the wrong tier

  • Parallel mode defaults to advanced, $5/1k, not fast at $1/1k.
  • Exa lite cannot live-fetch. A current price needs a type that accepts maxAgeHours=0.
  • A non-paying Tavily plan that sets max_age_hours can receive HTTP 434.
  • Perplexity Search API: standard $5/1k, fast $1/1k. Up to five queries in one request are still one billing unit. Not called from this repo.
  • Grounding with Google Search and Grounding with Bing are both $14/1k answer-grounding tools. Neither is Web IQ, and neither returns a raw result page. Bing Search APIs retired on 2025-08-11.
  • The Brave pricing dashboard rendered as a shell on the direct fetch. A research extract says $5/1k. This page does not treat that as a re-rendered list price.

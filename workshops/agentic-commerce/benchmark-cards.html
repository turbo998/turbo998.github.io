7 / 7 · MY TAKE GOOD FIT vs NOT FOR & READINESS

Use Web IQ Passage + Browse as the Real-Time Evidence Layer for Deterministic Commerce Agents

✅ Good Fit

• Personal shopping agents combining fast /v3/search/web passage discovery with pre-checkout HTTPS /v3/browse price & stock verification.

• Autonomous AP2 replenishment agents using /v3/search/news and /v3/auto (riskLevel) as a live safety/recall tripwire.

• Post-purchase customer support agents verifying live merchant return policies (liveCrawl="force") before Poppy operations confirmation.

• High-volume agent search workloads optimizing LLM token burn and MPP Tempo / x402 micropayment unit economics.

⛔ Not For

• Letting raw web snippets or crawled markdown directly invoke payment tools or modify CheckoutStore mandates without deterministic digest checks.

• Allowing consumer agents to run unguarded site: queries when safeSearch="strict" adult filtering is required.

• Treating HTTP 200 OK with "liveCrawlSucceeded": false or HTTP 202 Accepted (retryAfter) as a fresh merchant quote or return policy.

• Requesting contentFormat="markdown" on search endpoints without full-document entitlement (triggers 403 AuthContentFormatForbidden).

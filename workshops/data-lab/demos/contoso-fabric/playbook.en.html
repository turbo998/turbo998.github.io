2. Live Verification Queries (Copy & Run in Act 6 Lab)

1. Eventhouse KQL — 48h European Cross-Border Rebalance Pairing

ChannelInventoryTelemetry
| summarize arg_max(Timestamp, *) by DistributorId, ProductId
| where Region == 'Europe' and DynamicWOS < 1.5
| project DistributorId, DistributorName, Country, ProductId, OnHandUnits, HourlyBurnRate, DynamicWOS, RecommendedAction
| order by DynamicWOS asc

2. DirectLake DAX — Regional Sell-In vs OMO Sell-Out & Price Protection Exposure

EVALUATE
SUMMARIZECOLUMNS(
  'dim_subsidiaries'[Region],
  "NetSellInUSD", ROUND([Total Net Sell-In USD], 2),
  "RetailSellOutGMV", ROUND([Total Retail Sell-Out GMV USD], 2),
  "ChannelStockUSD", ROUND([Latest Channel Inventory USD], 2),
  "AvgWOS", ROUND([Avg Channel Weeks of Supply], 2),
  "PriceProtUSD", ROUND([Price Protection Exposure USD], 2)
)
ORDER BY [NetSellInUSD] DESC

3. SQL Endpoint — Prior-Gen Price Protection & Stockout Audit

SELECT
    d.Region,
    d.Country,
    i.DistributorId,
    d.DistributorName,
    i.ProductId,
    i.OnHandUnits,
    i.WeeksOfSupply,
    i.PriceProtectionExposureUSD,
    i.StockHealthStatus
FROM dbo.fact_channel_inventory_weekly i
JOIN dbo.dim_distributors d ON i.DistributorId = d.DistributorId
WHERE i.IsLatestSnapshot = 1
  AND (i.WeeksOfSupply < 1.5 OR i.PriceProtectionExposureUSD > 50000)
ORDER BY i.WeeksOfSupply ASC;

3. Top 8 Enterprise Customer Architecture Q&A

  • Q1: How do SAP S/4HANA ERP, partner EDI 852/867 feeds, and social/store POS land in OneLake without disruptive rewrites?
    SAP connects via ADF SAP CDC, SAP Datasphere federation, or Mirroring; overseas distributors drop EDI 852/867 into regional ADLS Gen2 / S3 mounted zero-copy via OneLake Shortcuts; POS and social surges stream codelessly via Real-Time Intelligence Eventstreams.
  • Q2: Why DirectLake instead of Power BI Import or DirectQuery?
    Import suffers multi-hour refresh lag and double memory footprint across global time zones; DirectQuery hammers operational SQL under concurrency. DirectLake maps V-Order Delta Parquet columns directly from OneLake into VertiPaq memory with sub-second response and zero data duplication.
  • Q3: How does Fabric IQ Ontology differ from a Power BI Semantic Model?
    Semantic Models aggregate KPIs (SUM/AVG) for human dashboards; Ontology models real-world operational objects (ChannelPartner, OceanContainerShipment), materializes a native Property Graph for multi-hop supply-chain blast-radius traversal, binds static Delta tables + live TimeSeries streams on the same entity, and enforces action guardrails subscribed by Operations Agents.
  • Q4: What about Tier-2 dealers sending messy Excel/CSV attachments by email?
    Land attachments into OneLake Files/external_partner_edi_raw and standardize SKU mappings via Fabric Data Pipelines + Spark/AI Functions into Silver Delta tables transparently beneath the Ontology.
  • Q5: How do we isolate Europe subsidiary pricing & rebates from North America or LATAM?
    Enforce OneLake Security + DirectLake RLS/OLS bound to Entra ID groups (SubsidiaryId = SUB-EU-DE). Both Power BI and Fabric Data Agent inherit the caller's Entra identity token via passthrough authentication.
  • Q6: How is this H5 cockpit embedded into Teams or an existing dealer portal in production?
    Backed exclusively by GA Power BI executeQueries, Kusto REST v2, and Fabric Job Scheduler APIs with Entra ID SSO, ready to embed as a Microsoft Teams Tab or internal operational portal.
  • Q7: What capacity sizing runs all 16 items?
    All 16 items (Lakehouse, Eventhouse, DirectLake, Ontology, Graph, Data Agent, 2 Operations Agents, Pipeline/Spark) share a single unified Fabric Capacity pool (F8 for PoC; F64+ in production to unlock license-free Power BI viewer distribution), with pause/resume automation when idle.
  • Q8: Recommended 4-Week Customer PoC Scope?
    1 core region (e.g., Europe or LATAM) + top 10 Tier-1 distributors/KAs + 2 high-ROI guardrails (48h promo stockout rebalance + prior-gen price protection). Week 1: OneLake Shortcuts; Week 2: DirectLake + 4-entity MVP Ontology; Week 3: Data & Operations Agents to Teams; Week 4: ROI readout & global rollout blueprint.

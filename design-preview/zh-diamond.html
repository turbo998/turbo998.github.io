03 / ARCHITECT DECISION GUIDE

Microsoft Fabric vs Azure Databricks vs 零拷贝共生架构选型指南

拒绝非黑即白的“推倒重来式”选型：根据客户现有数据团队技能栈、实时流处理需求与全员 BI 覆盖规模，选择最优的原生或零拷贝共生边界。

解决方案架构师选型矩阵 · FABRIC 原生 vs DATABRICKS 原生 vs 双平台零拷贝协同

何时选择 Microsoft Fabric 原生、Azure Databricks 原生，或双平台零拷贝共生架构？

架构评估维度 Microsoft Fabric 原生闭环（如 TCL 演示） Azure Databricks 原生重度工程 Fabric × Databricks 零拷贝共生（如 Zava 演示）
核心平台定位端到端 SaaS 一体化数据、实时智能、业务本体（Fabric IQ）与 M365 全员分析平台代码优先（Spark/Python/SQL）大规模数据工程、复杂特征管线与 AI 研发湖仓底座Databricks 负责重度清洗与 AI 建模；通过 OneLake 零拷贝镜像交由 Fabric 承载全员秒级 BI 与协同行动
存储与开放格式OneLake 开放 Delta Parquet + 跨云零拷贝 Shortcuts（ADLS / S3 / GCS）ADLS Gen2 开放 Delta Lake + Liquid Clustering 物理聚簇与预测性自动优化底层共享同一份 Delta Parquet，通过 Mirrored Catalog 秒级同步元数据，彻底消灭定时搬运 ETL
业务语义与智能体Fabric IQ 业务本体 + Data Agent 问数 + Operations Agent 业务规则回写Unity Catalog 指标视图 + AI/BI Genie 自然语言追因 + Mosaic AI 智能体数据团队用 Genie 深度追因，业务高管在 Power BI / Teams 用 Fabric IQ 与 Copilot 审批执行
实时流与事务闭环Real-Time Intelligence（Eventstreams + Eventhouse KQL 毫秒级时序分析 + Activator）Structured Streaming 流式管线 + DLT 声明式质检 + Serverless Lakebase 事务库Eventhouse 捕捉毫秒级航运/门店脉冲，Lakebase 与 Data Pipeline 持久化审批调拨回写
高管看数与消费成本原生 Power BI Direct Lake 直连 OneLake（亚秒级响应，免定时全量导入刷新）AI/BI 原生看板 + Serverless SQL Warehouse（按查询负载消耗 DBU 计费）Power BI Direct Lake 直接读取镜像黄金表，高并发高管看数实现 0 SQL Warehouse DBU 消耗
计费与 FinOps 模型单一统一容量池（F-SKU 跨数据集成、KQL、Spark 与 Power BI 削峰填谷共享）按作业类型计量 DBU + 弹性 Serverless 算力，支持细粒度集群配额与自动休眠将 Databricks DBU 聚焦于高价值 ETL/ML 算力，全员报表复用企业既有 Fabric 容量与 M365 许可
